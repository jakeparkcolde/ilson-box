# 강의 키트 진행 기록 · 2026-11-05

전달: 배포 관리 대상인 CLI의 `template/claude/skills/course-kit-20261109/`에 원본 MD를 포함한다. 새 설치의 setup에서 Box 폴더 안 `강의키트-20261109/`에 없는 파일만 복사한다. 기존 설치는 이 변경을 포함한 릴리스를 업데이트한 뒤 `ilson course-kit`을 실행한다. 업데이트 자체는 vault와 학생 파일을 건드리지 않는다. 설치 또는 명령 재실행 시 기존 파일을 보존한다. 아직 배포하지 않았으므로 기존 공개 버전에는 명령이 없다. 노션 공개·기기 검증과 릴리스는 별도 승인 사항이다.

검증: 합성 HOME에서 sandbox 설치 후 연습 파일 저장·닫기·재열기, 설치된 CLI 재실행, 기존 볼트와 강의 파일 보존, 두 번 실행 및 강의 폴더 링크 거부를 확인했다. 전체 시험은 별도 임시 복제본에서 모듈별 12병렬·stdin 차단으로 실행했다. macOS 격리가 `ps` 실행을 거부한 native-progress 모듈은 합성 HOME에서 격리 없이 재실행해 통과했다. 실제 학생 기기, 계정·네트워크, Intel·Windows, 노션 학생 접근 및 실제 배포는 확인하지 않았다. 강의 키트 원문을 공개 검사 패턴과 로컬 차단 목록으로 검색한 결과 해당 항목 0건이다.

## 실제 예시 교체 · 2026-11-05

부교재 v2.9의 실제 기록 기반 문구와 미실행 요청을 반영한다. 새 설치와 업데이트 뒤 `ilson course-kit`은 `강의키트-20261109-v2`에 없는 파일만 만든다. 이전 폴더와 새 폴더의 수정 파일을 덮어쓰지 않고 새 예시를 받을 수 있어 별도 폴더를 선택했다. 기존 파일의 개인 수정은 자동 병합하지 않으므로 필요한 내용은 사용자가 직접 옮긴다.

# Windows·Intel Mac 강의판 관리자 — 미공개 검증본

2026-11-15 로컬 구현입니다. 공개 설치기에 배포하지 않았으며 실제 Windows·Intel Mac 검증은 별도입니다. 공개 강의판에서 아직 명령이 없으면 강사가 검수한 업데이트 안내를 기다리세요.

## 열고 닫기

일반 터미널이나 PowerShell에서 `ilson open`을 실행합니다. 서버는 이 사용자 계정의 기기 안에서 배경 실행되고 기본 브라우저가 열립니다. 터미널 창을 닫아도 계속 사용할 수 있습니다. 같은 명령을 다시 실행하면 같은 서버를 재사용합니다.

`ilson admin status`는 실행 상태와 로컬 주소를 보여 줍니다. `ilson admin stop`은 서버를 정상 종료합니다. 응답이 없을 때만 `ilson admin stop --force`를 사용합니다. 기록된 PID의 실행 파일과 시작 시각이 맞는지 확인한 뒤 그 프로세스만 종료합니다.

관리자 탭을 닫고 마지막 인증 요청부터 2시간 동안 사용하지 않으면 자동 종료됩니다. 열린 탭은 1분마다 연결을 확인합니다. 로그오프·재부팅 뒤에는 자동 시작하지 않으며, 다시 `ilson open`을 실행합니다. 새 서비스나 예약 작업을 등록하지 않습니다.

## 다섯 화면

- **홈**: Claude 로그인, 회사 정보, 실습 폴더 신뢰, 라이선스를 확인합니다. 확인되지 않은 항목은 확인 불가로 표시합니다. 회사 정보는 Claude 대화에서 볼트의 `CONTEXT.md`에 정리하세요.
- **승인함**: Claude 대화에 `reports/pending/초안.md` 같은 Markdown 저장을 요청합니다. 저장된 초안을 선택하거나 파일 이름을 입력해 대기함에 추가하고, 본문과 대상을 모두 읽습니다. 승인하면 `reports/approved/`로 옮기고 `journal/`에 기록합니다. 수정 요청 뒤에는 Claude에서 고쳐 저장하고 새 요청을 추가합니다. 거절도 기록됩니다. 휴대폰 발송은 이번 단계에 없습니다.
- **주간 리포트**: 저장된 리포트를 읽습니다. 생성은 일반 터미널의 `ilson report weekly`를 사용합니다. 화면에서는 수정하거나 예약하지 않습니다.
- **내 AI 사용 기록**: Mac 관리자와 같은 그래프로 실습 폴더의 관측 날짜·본인 대화·세션·모델·토큰을 봅니다. 수집과 강사 공유는 각각 기본 꺼짐이며 본인이 안내를 읽고 따로 동의합니다. [자세한 안내](내-AI-사용-기록-보는-법.md)를 참고하세요.
- **답글 초안**: 고객 글을 직접 붙여 넣고 Claude 전송에 동의한 경우 초안을 만듭니다. 내용을 읽고 판매자센터에서 직접 게시합니다. 주문·배송·가격·분쟁 등은 직접 확인을 안내합니다.

## 저장 위치와 업데이트

Windows 코드는 `%LOCALAPPDATA%\ilson-course\lib`, 화면은 그 옆 `web`입니다. Intel Mac 코드는 `~/.ilson-course/lib`, 화면은 `~/.ilson-course/web`입니다. 토큰·실행 기록은 두 기종 모두 `~/.ilson-course/state/web-admin`, 승인 DB는 `~/.ilson-course/.approval`에 본인 전용으로 보관합니다. 비밀 상태는 Documents·OneDrive 아래에 두지 않습니다. 볼트는 기본 `Documents/일손강의-1기`이며 설치한 실습 폴더를 씁니다. 별도 경로는 기존 `ILSON_COURSE_VAULT`, 상태는 `ILSON_COURSE_STATE`를 사용합니다.

업데이트·재설치·롤백 전에 `ilson admin stop`을 실행하세요. 서버가 살아 있으면 코드 교체를 거절합니다. 알려진 배포 파일만 백업 후 교체하며, 사용자가 바꾼 도우미나 화면은 임의로 덮어쓰지 않습니다. 문서·개인 노트·PATH·기존 앱은 코드 롤백과 별개로 보존합니다.

서버는 `127.0.0.1`에만 열립니다. 다른 사용자에게 연결 토큰을 공유하지 마세요. 같은 사용자로 실행하는 프로그램과 시스템 관리자는 사용자 파일에 접근할 수 있습니다. 기본 포트를 다른 프로그램이 쓰면 그 프로그램은 유지하고 빈 포트를 선택합니다.

일반 화면은 라이선스가 필요합니다. 실행 중인 서버의 `/usage-history`에서는 만료·오프라인에도 본인 기록 읽기·끄기·내보내기·로컬 삭제가 가능합니다. 서버가 꺼져 있고 이용 권한을 확인할 수 없다면 기존 `ilson usage status|off|export|delete-local` 명령을 사용하세요. 공유 철회·서버 삭제는 `unlink`이며 인터넷이 없으면 완료 전까지 대기합니다.


Windows 검증본 설치 도구는 Claude Code · Herdr · Obsidian입니다. Herdr는 공식 x86_64 배포만 사용하며, 기존 Orca는 제거하지 않습니다. Intel Mac은 공식 Herdr 빌드 미지원으로 Orca를 유지합니다. 앱 설치가 core 설정·계정 로그인·원격 연결 완료를 뜻하지는 않습니다.

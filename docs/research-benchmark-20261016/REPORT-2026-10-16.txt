일손 검색 경로 실측 비교 — 2026-10-16

결론
이번 두 문항에서는 Codex 기본 검색 경로가 가장 정확하고 실용적이었다. Claude 기본 검색도 현재 일손 경로보다 나았다. Tavily 자체가 열등하다는 인과 결론은 낼 수 없다. 검색 공급자뿐 아니라 질의 생성, 원문 추출, 발췌, 재검색, 답변 프롬프트와 모델이 함께 달라진 전체 경로 비교다.

실행
일손 맥미니에서 동일 질문 2개 × 3경로 = 6회. 모두 정상 종료, 시간초과 없음.
현재 일손: research 0.15.3, deep/multi/baseline (Tavily 및 보조 검색 → 발췌 → Claude 답변).
Claude: 2.1.284, WebSearch/WebFetch만 허용, medium.
Codex: 0.158.0, live 내장 검색, medium, 읽기 전용, shell off.
일손과 Claude native 주 답변 모델은 로그상 claude-fable-5-1로 동일. Codex 실제 모델명은 수집 이벤트에서 확인되지 않았다.
운영 코드·리서치 설정·업무DB는 변경하지 않았다. 별도 폴더와 임시 GUI LaunchAgent에서 실행했다.

제품 비교
일손: M3의 포트를 Thunderbolt 4로 오기. 공식 사양은 2개 Thunderbolt 3/USB4. M4 포트 수·카메라·외장 화면 조건 등도 미확인으로 남겼다. 공식 자료 요청인데 비공식 및 Pro 칩 자료가 섞였다.
Claude: 핵심 사양은 정확. M3 덮개를 닫으면 외장 2대라는 조건은 찾았으나 macOS 14.6 이상 조건을 빠뜨렸다.
Codex: 포트, 카메라, 화면 수, M3의 OS/덮개/전원 조건까지 제시. 이번 문항에서 요청사항 충족도가 가장 높았다.

교육 비교
일손: 오래된 도서관 사례와 유아 미술 사례 등을 제시했지만 서울·초1·독서+미술 조건을 모두 충족한다고 확인할 수 있는 사례 3개를 확보하지 못했다. 연령·시간·가격 대부분 미확인. 모른다고 밝힌 점은 긍정적이나 실제 선택에 부족하다.
Claude: 구체적인 수업 3개를 제시했으나 2개는 2차 보도자료와 연도·시간·가격 미확인에 의존. 현재 모집 사례는 확보하지 못했다.
Codex: 증산도서관(현재 모집), 중곡문화체육센터도서관(2024년 공고), 서울백제어린이박물관(2026년 7월 공고)을 공식 페이지로 연결. 가격 공란을 무료라고 추정하지 않고 시간·대상·책과 만들기 연결을 구분했다. 실제 개최 완료까지 증명한 것은 아니다.

해석과 다음 단계
현행 코드의 검색 결과 병합·관련 부분 발췌 이후 답변 모델은 추가 검색을 할 수 없다. 필요한 원문 구간이 빠지거나 부적합한 자료가 선정되면 답변 단계에서 복구하기 어렵다. 이번 결과와 코드 검토를 함께 보면 이 흐름이 개선 우선순위다. 단일 원인으로 입증한 것은 아니다.
Codex 기본 검색을 리서치 선택 경로로 추가해 10~20개 실제 업무 질문에서 반복 평가하는 것을 권한다. Tavily는 이 결과만으로 삭제하지 않고 구조화 수집·URL 추출 등 용도와 비교 가능성을 보존한다.
평가는 정확성, 공식 근거, 요청항목 완성도, 시점 구분, 시간으로 나누고 같은 모델·공통 프롬프트를 맞춘 추가 시험이 필요하다.

한계
각 경로/문항 1회, 총 2문항이다. 순위 일반화 불가. Perplexity는 이번 시험에 포함하지 않았다. native와 기존 경로의 출력 형식·검색 예산·프롬프트가 다르다. API 환산 비용을 실제 구독 청구액으로 비교하지 않았다.

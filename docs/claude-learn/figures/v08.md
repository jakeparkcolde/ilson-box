# Figure briefs — v08 개인정보 안내 붙이기 (심화 8강)

Common rules: SPEC §8a and `FIGURE-STYLE.md` (SVG only, viewBox width 720, height ≤ 480, light plate `#f5f6f6`, palette tokens, Korean font stack, ≤ ~12 words per label, no logos, no government emblems or seals). Every text at least 18px at the 720 design width (main labels 20–24px). File names in mono 18–20px. Placeholders are never drawn: the page shows the example shop 「햇살꽃집」. **Never draw a retention period as a fact**: wherever the period appears, write 「내가 정한 기간」 (the lesson's "6개월" is only an example). No phone numbers or names. **Keep a clear zone of about 120 × 72 px in the bottom-right corner of every figure (zoom badge).**

Colour meaning in this lesson: purple = what the reader adds or decides; amber = 「[확인 필요]」 and 「[전문가 확인]」; green = done / consistent.

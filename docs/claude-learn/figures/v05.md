# Figure briefs — v05 Supabase에 예약 상자 만들기 (심화 5강)

Common rules: SPEC §8a and `FIGURE-STYLE.md` (SVG only, viewBox width 720, height ≤ 480, light plate `#f5f6f6`, palette tokens, Korean font stack, ≤ ~12 words per label, no logos — Supabase is plain text, no green brand mark, no lightning glyph). Every text at least 18px at the 720 design width (main labels 20–24px). Table and column names in mono 18–20px. Placeholders are never drawn. Never draw a real project URL, a key value, a password or a UID; key prefixes appear only as `sb_publishable_…` / `sb_secret_…`. **Keep a clear zone of about 120 × 72 px in the bottom-right corner of every figure (zoom badge).**

Our own image for this lesson: the reservation table as a **paper order form with white boxes and grey boxes** — the customer fills only the seven white boxes; the four grey boxes belong to the shop. Do not draw a lock, safe, key ring, warehouse, door, wristband, spreadsheet grid or delivery window.

Colour meaning in this lesson: purple = what the reader does / where to look; green = allowed, passes; red = refused (42501); grey `#eceef0` boxes = shop-only columns.

# Figure briefs — v10 오래 운영하기 (심화 10강)

Common rules: SPEC §8a and `FIGURE-STYLE.md` (SVG only, viewBox width 720, height ≤ 480, light plate `#f5f6f6`, palette tokens, Korean font stack, ≤ ~12 words per label, no logos, no calendar app or clock brand imagery). Every text at least 18px at the 720 design width (main labels 20–24px). SQL markers and file names in mono 18–20px. Placeholders are never drawn. No retention period drawn as advice (use 「내가 정한 기간」); no prices in these figures. **Keep a clear zone of about 120 × 72 px in the bottom-right corner of every figure (zoom badge).**

Our own image: three care rhythms drawn as three plain bands of different length (short = every few days, medium = weekly, long = monthly) — not a calendar grid, not a watering can, not an alarm clock.

Colour meaning in this lesson: purple = what the reader does; green = read-only / safe; amber = careful; red = cannot be undone / customer data at risk.

# Figure brief: b03 「안심하고 쓰기」

Lesson JSON: `template/web/current/learn/lessons/b03.json`. Output folder: `template/web/current/learn/img/`.

Rules for every figure (SPEC §8a): SVG only, `viewBox` width 720, no scripts, no `foreignObject`, no external refs, no raster, no web fonts, at most 60 KB.
Font `Apple SD Gothic Neo, Pretendard, 'Noto Sans KR', sans-serif`; every label at least 18px at 720 wide (FIGURE-STYLE.md: heading 26–30px, main label 20–24px, secondary 18px). If a label below gets too wide at that size, wrap it onto two lines; never shrink it. Where a colour, arrow or badge hint in this brief differs from FIGURE-STYLE.md, FIGURE-STYLE.md wins.
Allowed SVG elements only (tests/test_learn.py ALLOWED_SVG): svg, g, defs, title, desc, rect, circle, ellipse, line, polyline, polygon, path, text, tspan, linearGradient, radialGradient, stop, clipPath, marker, symbol, use, style. **No `<filter>`**: draw shadows as a slightly darker offset rect.
Palette: plate `#ffffff`/`#f5f6f6`, ink `#1d1d21`, secondary `#6b7078`, hairline `#e4e4e8`, accent `#5e6ad2` (soft `#e8eafb`), success `#1d8a38`, caution `#a3720a`, danger `#c4423b`. Corners 12–16.
No logos. Copy Korean labels exactly. English UI labels appear only where listed (confirmed in FACTS).
Any name, phone number or address in these figures must be the obviously fake ones given here. Never invent other personal data.

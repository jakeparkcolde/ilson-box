# Figure briefs — v09 Vercel에 올리기 (심화 9강)

Common rules: SPEC §8a and `FIGURE-STYLE.md` (SVG only, viewBox width 720, height ≤ 480, light plate `#f5f6f6`, palette tokens, Korean font stack, ≤ ~12 words per label, no logos — Vercel and GitHub are plain text, no triangle mark, no octocat). Every text at least 18px at the 720 design width (main labels 20–24px). Commands and addresses in mono 18–20px; the public address is always drawn as `…vercel.app` (never a made-up full domain). English UI labels only those in FACTS-VIBE V8: New Project, Framework Preset, Other, Build Output Settings, Output Directory, Override, Deploy, Production, Preview, Instant Rollback, Undo Rollback, Hobby, Pro. Prices only as in the lesson: Hobby $0, Pro 월 $20 (부가세 별도), with 「2026-10-21 기준」. **Keep a clear zone of about 120 × 72 px in the bottom-right corner of every figure (zoom badge).**

Colour meaning in this lesson: purple = what the reader does; green = allowed / customer-facing and fine; amber = careful (paid plan, rollback state); red = not allowed (a real shop on Hobby).

# Figure briefs — v03 안내 페이지를 예약 화면으로 (심화 3강)

Common rules: SPEC §8a and `FIGURE-STYLE.md` (SVG only, viewBox width 720, height ≤ 480, light plate `#f5f6f6`, palette tokens, Korean font stack, ≤ ~12 words per label, no logos, no browser brand marks). Every text at least 18px at the 720 design width (main labels 20–24px). File names in mono 18–20px. Placeholders are never drawn: the page title uses the example shop 「햇살꽃집 안내」. Never draw a phone number, address, opening hours or a real person's name; the practice name shown in a field is 「연습 손님」. **Keep a clear zone of about 120 × 72 px in the bottom-right corner of every figure (zoom badge).**

Colour meaning in this lesson: purple = what the reader clicks / where to look; amber = 「[확인 필요]」; green = the friendly practice message.

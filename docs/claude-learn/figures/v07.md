# Figure briefs — v07 사장님만 보는 예약함 (심화 7강)

Common rules: SPEC §8a and `FIGURE-STYLE.md` (SVG only, viewBox width 720, height ≤ 480, light plate `#f5f6f6`, palette tokens, Korean font stack, ≤ ~12 words per label, no logos). Every text at least 18px at the 720 design width (main labels 20–24px). SQL and code in mono 18–20px. Placeholders are never drawn. **Never draw a real or realistic UID**: where the owner id appears, write 「(복사한 아이디)」 in Korean; the placeholder `여기에-사장님-아이디` from the SQL file may be shown. No real names, emails or phone numbers (use 「연습 손님」). **Keep a clear zone of about 120 × 72 px in the bottom-right corner of every figure (zoom badge).**

Our own image: the owner's id is the one name on the list the rule checks — draw it as a single highlighted row (purple) in an otherwise grey list, not as a key, badge, wristband or door.

Colour meaning in this lesson: purple = the owner / what the reader edits; green = allowed; red = refused or 0건; amber = the two ★ places to edit.

# Figure briefs — v04 하루 마감 저장점 (심화 4강)

Common rules: SPEC §8a and `FIGURE-STYLE.md` (SVG only, viewBox width 720, height ≤ 480, light plate `#f5f6f6`, palette tokens, Korean font stack, ≤ ~12 words per label, no logos — GitHub is plain text, no octocat, no game or save-slot imagery). Every text at least 18px at the 720 design width (main labels 20–24px). Commands and file names in mono 18–20px. Placeholders are never drawn. **Keep a clear zone of about 120 × 72 px in the bottom-right corner of every figure (zoom badge).**

Our own image for git in this track is the 「마감 사진첩」: each closing, one page with a snapshot of the work folder and a one-line note underneath. Draw it as a simple album with paper pages and a folder sketch inside each photo frame — not a camera brand, not a game save, not a calendar.

Colour meaning in this lesson: purple = what the reader does; green = saved / private and safe; red = never (force push, secrets).

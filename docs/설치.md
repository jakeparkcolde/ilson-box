# 일손 설치 안내

이 종이 한 장이면 됩니다. 컴퓨터를 잘 몰라도 괜찮습니다.

---

## 준비물

- **맥미니** (전원과 인터넷선이 꽂혀 있을 것)
- **설치 코드** — 저희가 따로 알려드린 `XXXX-XXXX` 형식의 여덟 글자
- 인터넷

맥미니 화면·키보드·마우스는 설치할 때만 필요합니다. 설치가 끝나면 전원만 꽂아두시면 됩니다.

---

## 1. 터미널 열기

1. 맥미니 화면 오른쪽 위 **돋보기(🔍)** 를 누릅니다
2. `터미널` 이라고 칩니다
3. 맨 위에 나오는 **터미널** 을 누릅니다

검은(또는 흰) 글자 창이 하나 뜹니다. 여기에 글자를 붙여넣을 겁니다.

---

## 2. 한 줄 붙여넣기

아래 한 줄을 **통째로 복사해서** 터미널에 붙여넣고 `Enter` 를 누릅니다.

```
curl -fsSL https://<주소>/install.sh | sh
```

> 이 주소는 계약하실 때 저희가 정확한 것으로 채워 드립니다.

글자들이 주르륵 올라갑니다. 마지막에 이렇게 나오면 성공입니다.

```
설치 끝 — ...

다음 한 줄을 실행하세요 (설치 안내문에 적힌 코드로):

    ilson init --code XXXX-XXXX
```

---

## 3. 코드 넣고 짓기

화면에 나온 그대로, `XXXX-XXXX` 자리에 **저희가 드린 여덟 글자** 를 넣어 칩니다.

```
ilson init --code ABCD-1234
```

이제 일손이 자기 자리를 만듭니다. 중간에 이런 것들이 뜹니다.

| 뜨는 것 | 하실 일 |
|---|---|
| **비밀번호를 묻습니다** | 맥미니 로그인 비밀번호를 칩니다. (**글자가 안 보이는 게 정상입니다** — 그냥 치고 Enter) |
| **"권한을 허용하시겠습니까?"** 창 | **허용** 을 누릅니다 |
| **"열려면 확인이 필요합니다"** 창 | **열기** 를 누릅니다 |

몇 번 물어볼 수 있습니다. 전부 **허용/열기** 를 눌러 주세요. 이건 일손이 알림을 보내고 예약 업무를 돌리기 위해 꼭 필요한 것들입니다.

---

## 4. 첫 출근 인터뷰

마지막에 일손이 **사장님께 회사에 대해 물어봅니다.** 대화하듯 답해 주시면 됩니다.

- 무슨 일을 하는 회사인지
- 누가 무슨 일을 맡고 있는지
- 매일 아침 뭘 알고 싶으신지

여기서 답해주신 내용이 일손의 **첫 교과서** 가 됩니다. 아는 만큼만 답하셔도 되고, 나중에 얼마든지 더 알려줄 수 있습니다.

대화가 끝나면 `/exit` 를 치고 Enter 를 누릅니다.

---

## 5. 다 됐는지 확인

터미널에 이렇게 칩니다.

```
ilson doctor
```

**✅ 가 죽 늘어서고 ❌ 가 없으면 끝났습니다.** 곧 텔레그램으로 첫 인사가 갑니다.

❌ 가 남아 있으면 그 줄을 **사진으로 찍어 저희에게 보내주세요.** 남은 건 저희가 처리합니다.

---

## 이제 하실 일

**없습니다.** 맥미니는 전원만 꽂아두시면 됩니다. 화면·키보드는 뽑으셔도 됩니다.

- 매일 아침 텔레그램으로 브리핑이 갑니다
- 일손에게 뭘 시키는 방법은 **[사용법](사용법.md)** 에 있습니다

---

## 잘 안 될 때

| 이런 일이 | 이렇게 |
|---|---|
| `command not found: ilson` | 터미널을 **닫았다 다시 열고** 같은 줄을 다시 칩니다 |
| 중간에 멈췄다 | 같은 `ilson init --code ...` 를 **다시 치면 됩니다.** 이미 된 건 건너뜁니다 |
| 비밀번호가 안 쳐진다 | 안 보이는 게 정상입니다. 그냥 치고 Enter |
| 그 외 전부 | `ilson doctor` 결과를 **사진 찍어 보내주세요** |

무엇을 잘못 눌러도 **회사 데이터가 사라지는 일은 없습니다.** 편하게 해보셔도 됩니다.

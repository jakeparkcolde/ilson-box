# 일손 Box 설치

새 맥미니의 macOS 기본 설정을 마치고 터미널을 엽니다.

## 1. 한 번에 기본 설치

```sh
curl -fsSL https://raw.githubusercontent.com/jakeparkcolde/ilson-box/main/install.sh | sh
```

처음 설치하거나 기존 CLI를 업데이트할 때 같은 명령을 사용합니다. 도구·볼트·예약 업무 파일까지 준비합니다. Homebrew 설치에 관리자 비밀번호가 필요할 수 있습니다. 비밀번호를 입력할 때 화면에 글자가 보이지 않는 것은 정상입니다.

CLI는 `~/.ilson-cli`, 회사 기록은 `~/ilson/vault`에 놓입니다. 설치코드는 필수가 아닙니다. 오류가 나면 같은 설치를 다시 실행할 수 있으며 기존 회사 노트와 연결 설정은 보존합니다.

### 설치 후 열리는 내 일손 화면

기본 구성 뒤 웹 관리자가 이 맥의 브라우저에서 열립니다. 처음 설정하는 순서, 업무 일정과 등록 상태, 보고서를 볼 수 있습니다. 웹 관리자가 열려도 예약 업무는 아직 시작하지 않습니다.

다시 열 때는 `ilson open` 또는 `~/ilson/일손 열기.command`를 두 번 누르세요. 창을 닫아도 관리자 서비스와 이미 시작한 예약 업무는 유지됩니다. 관리자는 이 맥에서만 접속하며 외부 공개 주소를 자동 생성하지 않습니다.

로그인·폴더 신뢰·회사 인터뷰·텔레그램 연결은 화면에서 안내된 명령을 복사해 본인 터미널에서 진행합니다. 웹 화면에 토큰이나 계정 비밀번호를 입력하지 않습니다. 포트 사용 중 오류가 나오면 `ilson open --port 18795`처럼 다른 포트로 열 수 있습니다. 기존 서비스를 강제 종료하지 않습니다.

### 설치 중 텔레그램 알림 연결

1. **지금 연결**을 선택합니다. 토큰이 없다면 텔레그램의 공식 [BotFather](https://t.me/BotFather)에서 `/newbot`으로 봇을 만듭니다.
2. 발급받은 토큰을 터미널의 숨김 입력창에 붙여넣고 Enter를 누릅니다. 글자가 보이지 않는 것이 정상입니다.
3. 봇 확인 후 열리는 텔레그램에서 **시작(Start)**을 누릅니다. 창이 열리지 않으면 터미널에 나온 링크를 직접 엽니다.
4. 받을 개인 대화를 확인하고 저장합니다. 대화 ID를 직접 찾거나 설정 파일을 편집할 필요가 없습니다.

토큰은 AI 대화나 회사 노트에 붙여넣지 않습니다. **나중에**를 선택했거나 연결 시간이 지났다면 일반 터미널에서 다시 실행하세요.

```sh
ilson telegram connect
ilson telegram status --verify
```

이미 연결한 기기는 재설치해도 그대로 보존합니다. 봇·받을 계정을 변경하려면 `connect`를 실행하고 교체 안내를 확인합니다. 기존 설정은 새 연결 검증에 성공했을 때만 바뀝니다.
`status`는 저장 상태, `status --verify`는 Telegram의 봇·대화 응답을 확인합니다. 점검은 메시지를 보내지 않으며 실제 알림 수신 여부는 첫 업무 보고에서 확인합니다.

다른 서비스에서 사용 중인 봇 때문에 webhook·수신 충돌 안내가 나오면 일손 알림용 봇을 별도로 만드세요. 기존 서비스 설정이나 대기 메시지는 자동 삭제하지 않습니다.
자동 설치처럼 입력창이 없는 환경에서는 연결을 건너뛰고 위 명령을 안내합니다. 기존 CLI에 이 기능을 추가할 때는 위 설치 명령을 다시 실행해야 합니다(`ilson update`는 CLI를 갱신하지 않습니다).

## 2. 본인 계정 로그인과 회사 인터뷰

새 터미널을 열고 다음을 실행합니다.

```sh
cd ~/ilson
claude /onboard
```

본인 Claude 구독으로 로그인하고 이 폴더의 신뢰 여부를 확인합니다. 회사에 관한 질문에 답하고, 회사 정보가 저장됐으면 `/exit`로 나옵니다. Codex는 `codex`를 실행해 본인 ChatGPT 계정으로 로그인합니다.

Tailscale 앱을 열어 다른 기기와 같은 네트워크에 로그인하세요. Obsidian에서는 `~/ilson/vault`를 기존 볼트로 엽니다. 이 로그인과 동의는 설치기가 대신하지 않습니다.

## 3. 상시 가동 설정과 업무 시작

```sh
ilson setup --configure-machine
ilson start
ilson doctor
```

첫 명령은 관리자 비밀번호를 받아 잠자기 방지와 정전 후 재시작을 설정합니다. `start`는 로그인과 회사 정보가 준비됐는지 확인하고 예약 업무를 등록합니다. FileVault와 화면 잠금은 유지합니다. 재부팅 후에는 사람이 잠금을 풀고 로그인해야 합니다.

`command not found: ilson`이 나오면 터미널을 다시 열거나 `~/.ilson-cli/ilson`으로 실행하세요.

## 4. 관리 대화 열기

```sh
ilson chat
```

일손 폴더에서 `claude --permission-mode auto`를 실행합니다. 설치·업데이트·업무 등록을 요청하면 해당 작업까지 진행하도록 구성했습니다.
현재 Claude 창 안에 설치 명령을 다시 넣기보다 `/exit`로 나온 일반 터미널에서 설치를 마친 뒤 이 명령으로 새 대화를 여세요.
auto 모드가 지원되지 않거나 다른 정책이 막으면 이유를 확인하며, 모든 권한 검사를 끄는 모드로 자동 전환하지 않습니다.
예약 실행은 별도 권한이며, 설치 후 실제 보고서 작성과 검색이 허용되는지 새 맥에서 시험해야 합니다.

## 남은 선택 연결

- 텔레그램: 설치 중 건너뛰었다면 `ilson telegram connect`로 알림을 연결합니다. 연결 전에도 보고서는 볼트에서 확인할 수 있습니다. 텔레그램에서 업무 지시를 받는 기능은 아직 포함하지 않습니다.
- Aside: 브라우저 업무를 사용할 때 설치·연결합니다. 기본 브리핑에는 필수가 아닙니다.
- macOS 권한: 사용하는 기능이 요청할 때 대상 앱과 권한을 확인하고 허용합니다.

Tailscale 첫 설치와 기존 연결은 다음처럼 안내합니다.

| 표시 | 할 일 |
|---|---|
| 로그인 대기 | 새 맥에서 앱을 열어 로그인하고 요청되는 VPN 권한 승인 |
| 초기화 대기 | 앱 시작과 권한 승인을 마친 뒤 재점검 |
| 기기 승인 대기 | 네트워크 관리자에게 기기 승인 요청 |
| 연결 꺼짐 | 앱에서 연결 상태 확인 |
| 연결 상태 확인 | 기존 연결 그대로 사용 |
| 상태 확인 불가 | 기존 연결을 유지하고 일반 터미널 또는 앱에서 상태 확인 |

이 대기/조회 불가 상태 때문에 기본 설치를 실패로 종료하지 않습니다. 연결이 확인되기 전에는 원격 설정 완료로도 표시하지 않습니다. 로그인/권한 처리를 마치면 재설치 없이 `ilson doctor`로 다시 점검하세요. `doctor`의 종료 코드 1은 진단 미완료를 뜻할 수 있으며 파일 설치 실패와 별개입니다. 실제 첫 보고·재부팅 후 복구까지 확인해야 설치 검증이 끝납니다.

## 기본 검색 확인

Tavily CLI와 일손 검색 스킬은 기본 설치에 포함됩니다. 일반 `doctor`는 설치만 확인합니다.
`ilson doctor --probe-search`는 공개 검색 1회를 실제 실행하며 검색 크레딧을 사용할 수 있습니다.
무인증 사용에는 한도가 있으므로 예약 검색은 새 맥에서 `tvly login`을 직접 진행한 뒤 확인하세요.
원격 세션의 브라우저 로그인 콜백은 새 맥으로 돌아가야 합니다. 로그인은 새 맥의 화면에서 진행하는 것이 간단합니다.
기존 기기의 키·로그인 파일을 복사하지 않습니다. 기본 브리핑에 뉴스 검색을 자동 추가하지 않으며 검색 주제·일정은 별도로 정합니다.

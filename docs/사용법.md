# 일손 사용법

`ilson start`로 예약 업무를 켠 뒤 정해진 시각에 실행됩니다. 이 문서는 "무엇을 알아서 하는지"와 "무엇을 더 시킬 수 있는지"를 알려드립니다.

## 웹에서 확인하기

일반 터미널에서 `ilson open`을 실행하거나 `~/ilson/일손 열기.command`를 두 번 누르면 내 일손 관리자가 열립니다. 홈에서 준비 상태, 내 업무에서 일정·등록 상태·최근 성공 기록, 보고서에서 결과를 확인합니다. 아직 보고서를 만들지 않았다면 빈 목록과 첫 실행 안내가 보입니다.

현재 실행 여부나 실패 내역을 확인할 근거가 없으면 미확인으로 표시합니다. 과거 성공 기록이 있다는 이유로 현재 정상 실행 중이라고 판단하지 않습니다. 설정 화면의 명령은 복사 후 터미널에서 실행해야 적용됩니다. 웹에서 일정 변경·업무 실행·발송 승인은 아직 제공하지 않습니다.

`ilson admin stop`은 웹 관리자만 중지하고, `ilson open`으로 다시 열 수 있습니다. 예약 업무를 멈추는 명령은 아닙니다. 다른 컴퓨터나 휴대폰 접속은 별도 연결이 필요하며, 기본 설치는 인터넷에 공개하지 않습니다.

---

## 1. 일손이 알아서 하는 일

`ilson start` 이후 아래 일정으로 실행합니다. 텔레그램은 설치 중 안내에 따라 연결하거나 `ilson telegram connect`로 연결해야 전송됩니다.

| 언제 | 무엇을 | 사장님이 받는 것 |
|---|---|---|
| **매일 아침 8시** | 아침 브리핑 | 텔레그램 한 화면 — 어제 기록, 오늘 할 일 |
| **금요일 오후 5시** | 주간 보고 | 텔레그램 — 이번 주를 한 장으로 |
| **매일 밤 11시 반** | 위키 정리 | (조용히) 그날 쌓인 노트를 정돈 |
| **10분마다** | 업무 점검 | 문제가 있을 때만 텔레그램 경보 |
| **10분마다** | 복구용 기록 | (조용히) 되돌릴 수 있게 저장 |
| **매일 오전 9시 반** | 일손 업데이트 | (조용히) 저희가 개선한 것을 받아감 |

맥미니는 켜져 있고 잠자기에 들어가지 않아야 합니다. 재부팅 후에는 로그인해야 사용자 예약 업무가 재개됩니다.

업무를 잠시 쉬게 하려면 터미널에서 `ilson pause tidy`처럼 실행하고, 다시 켤 때는 `ilson resume tidy`를 실행합니다. 다시 켤 때는 지금의 일정 설정으로 등록합니다. 업무 점검·복구용 기록·일손 업데이트는 Box 보호에 필요해 멈출 수 없습니다. 실행 중인 업무를 멈추면 그 회차는 바로 끝나고 알림과 성공 기록은 남지 않습니다(그 사이 고친 파일은 남을 수 있습니다). 웹 관리자의 업무 화면은 실제 등록된 일정을 보여주고, 설정 파일과 다르면 다시 등록하라는 안내를 함께 표시합니다.

## 2. 직접 시키고 싶을 때

맥미니 터미널에서 아래처럼 부르면 됩니다. (원격으로 부르는 방법은 저희가 따로 열어드립니다.)

```
ilson chat
```

Claude 가 열리면 아래 네 가지를 칠 수 있습니다.

관리 대화는 `auto` 모드로 열립니다. 요청받은 설치·업데이트·설정·예약 업무 등록까지 처리할 수 있습니다. 관리자 비밀번호나 중요한 외부 행동의 확인은 남을 수 있습니다. 자동 심사 미지원 시 권한 우회로 바꾸지 않고 환경을 확인합니다.

| 치는 것 | 하는 일 |
|---|---|
| `/briefing` | 아침 브리핑을 **지금** 한 번 더 |
| `/weekly` | 주간 보고를 **지금** 만들기 |
| `/tidy` | 위키를 **지금** 정리 |
| `/onboard` | 회사 이야기를 **더 알려주기** (첫날 인터뷰의 이어달리기) |

그냥 **평범한 한국어로 부탁하셔도 됩니다.**

> "지난주 매출 얘기 어디에 적어놨지?"
> "거래처 김 사장님 미팅 내용 기록해줘"
> "이번 달 정리해서 보여줘"

웹 검색도 요청할 수 있습니다. 예: "최근 일주일 반려동물 간식 업계 뉴스를 출처와 함께 찾아줘".
Tavily CLI와 일손 검색 스킬은 기본 설치에 포함됩니다. 인증·한도에 따라 검색이 실패할 수 있으므로
`ilson doctor --probe-search`로 실제 응답을 확인하세요. 기본 예약 브리핑은 내부 기록 요약이며 외부 뉴스는 주제·일정을 정한 뒤 연결합니다.

끝내실 땐 `/exit` 를 칩니다.

## 3. 일손의 기억 — 볼트

일손이 아는 것은 전부 `~/ilson/vault/` 폴더 안에 **읽을 수 있는 글**로 있습니다. 숨겨둔 게 없습니다.

```
vault/
├── CONTEXT.md      회사 한 장 요약 — 일손이 매번 제일 먼저 읽는 것
├── company/        회사에 대해 배운 것들 (사람·거래처·제품·규칙)
├── journal/        날짜별로, 그날 무슨 일이 있었는지
├── lessons/        사장님께 지적받은 것 — 다시 안 틀리려고
└── reports/
    ├── briefing/   지나간 아침 브리핑
    ├── weekly/     지나간 주간 보고
    └── pending/    ⭐ 사장님 승인을 기다리는 초안
```

**옵시디언(Obsidian)** 앱으로 이 폴더를 열면 위키처럼 보고 고칠 수 있습니다. 사장님이 직접 고쳐 쓰셔도 됩니다 — 일손은 그걸 그대로 배웁니다.

### 일손이 틀린 말을 하면

`vault/lessons/` 에 한 줄 적어두시면 됩니다. 다음 업무에서 읽도록 지시합니다. 실제 반영 여부는 결과를 확인해 주세요.

## 4. 일손이 지키는 약속

설치할 때 함께 깔리는 행동 규칙입니다. 모든 외부 동작을 기계적으로 차단한다는 보장은 아니며 실제 실행 권한도 확인해야 합니다.

**① 밖으로 나가는 건 승인 없이 안 합니다**

메일·문자·SNS·결제·삭제 — 회사 밖으로 나가는 일은 **초안까지만** 만들고 `vault/reports/pending/` 에 둡니다. 사장님이 보고 "보내"라고 하셔야 나갑니다.

> 텔레그램 알림만 예외입니다. 사장님께 보고하는 통로니까요.

**② 없는 사실은 지어내지 않습니다**

회사 내부 수치·기간·성과는 볼트에 적힌 것만 말합니다. 모르면 **"기록에 없습니다"** 라고 합니다.
외부 검색 정보는 출처 URL·조회일을 붙이고 회사 내부 기록과 구분합니다.

**③ 관리와 예약 실행의 권한을 나눕니다**

관리 대화에서는 요청받은 업무에 필요한 설정과 파일을 수정할 수 있습니다. 무인 예약 실행은 별도 권한으로 볼트 문서 작성과 검색을 수행하며 설치·설정 변경 권한을 상속하지 않습니다. 이 구분은 운영 권한이며 맥 전체를 격리하는 보안 장벽은 아닙니다.

**④ 비밀은 적지 않습니다**

비밀번호·토큰 같은 것은 보고서나 노트에 절대 쓰지 않습니다.

## 5. 문제가 생기면

터미널에서 이 한 줄이면 대부분 알 수 있습니다.

```
ilson doctor
```

✅ 와 ❌ 로 상태를 보여줍니다. **❌ 가 있으면 그 화면을 사진 찍어 보내주세요.**

| 이런 일이 | 이렇게 |
|---|---|
| 아침 브리핑이 안 온다 | `ilson doctor` → 사진 |
| 맥미니를 껐다 켰다 | 로그인 후 예약 업무가 재개되는지 `ilson doctor`로 확인합니다 |
| 일손이 이상한 소리를 한다 | `vault/lessons/` 에 한 줄 적어주세요 |
| 새 기능을 쓰고 싶다 | 저희에게 말씀만 주세요. 다음 업데이트로 갑니다 |

## 6. 그만두고 싶으실 때

먼저 예약 업무의 launchd 등록을 해제하고 회사 기록을 백업해야 합니다. `~/ilson` 폴더만 삭제하면 예약 서비스 등록은 남습니다. 기록은 `~/ilson/vault`의 문서로 보관되므로 일손 없이도 읽을 수 있습니다.

가둬두지 않습니다.

### 대화에서 직원 등록

`ilson chat`에서 Claude 또는 Codex에 이름과 역할을 정해 직원 등록을 요청합니다. Claude에서는 `/employee` 명령도 사용할 수 있습니다. Codex 진입 시에는 시작 프롬프트로 Box의 `CLAUDE.md`와 등록 절차 문서를 읽도록 연결하며, 사용자 `AGENTS.md`·`AGENTS.override.md`나 전역 설정은 변경하지 않습니다. 세션은 `ilson people`로 관리자와 같은 직원 장부에 저장하고 확인된 직원 ID를 알려줍니다. 이름·역할이 없으면 먼저 질문합니다. 업데이트 전에 열었던 대화는 새로 열거나 Box의 `CLAUDE.md`와 `.claude/commands/employee.md`를 다시 읽어야 합니다.

일반 터미널에서도 다음을 사용할 수 있습니다. `ILSON_HOME`은 실제 사용하는 Box 폴더로 설정하세요. 관리자가 꺼져 있으면 같은 Box에서 `ilson open`을 실행합니다.

```sh
ILSON_HOME="<Box 폴더>" ilson people list
ILSON_HOME="<Box 폴더>" ilson people add --name "문서 담당" --role "회의 기록 작성" --request-id "<한 번 생성한 고유 요청 ID>"
ILSON_HOME="<Box 폴더>" ilson people get <확인한 직원 ID>
```

요청 ID는 `python3 -c 'import uuid; print(uuid.uuid4().hex)'`로 생성할 수 있습니다. 재시도에는 같은 ID와 같은 입력을 사용하세요. 동명이인 등록은 허용하며 새 요청 ID는 새 직원으로 처리됩니다. 이미 수정한 직원을 재시도로 덮어쓰거나 삭제한 직원을 되살리지 않습니다. 성공은 종료 코드 0과 JSON의 `ok: true` 및 `id`로 확인합니다. 토큰을 출력하거나 DB를 직접 편집하지 않습니다.

열린 직원·조직도 목록은 보이는 동안 약 2초 간격으로 자동 갱신됩니다. 편집 중 입력·부서 선택·스킬 선택은 그대로 유지되며, 다른 곳에서 수정된 항목을 오래된 폼으로 저장하면 충돌을 알려줍니다. 연결 오류·만료 시 입력을 유지하고 안내를 표시합니다. 다시 연결하거나 선택 항목이 삭제된 경우 최신 목록을 확인하고 편집을 다시 열어주세요.

# 일손 사용법

설치가 끝났다면 일손은 **이미 일하고 있습니다.** 이 문서는 "무엇을 알아서 하는지"와 "무엇을 더 시킬 수 있는지"를 알려드립니다.

---

## 1. 일손이 알아서 하는 일

시키지 않아도 정해진 때에 스스로 합니다.

| 언제 | 무엇을 | 사장님이 받는 것 |
|---|---|---|
| **매일 아침 8시** | 아침 브리핑 | 텔레그램 한 화면 — 어제 기록, 오늘 할 일 |
| **금요일 오후 5시** | 주간 보고 | 텔레그램 — 이번 주를 한 장으로 |
| **매일 밤 11시 반** | 위키 정리 | (조용히) 그날 쌓인 노트를 정돈 |
| **10분마다** | 건강 점검 | 문제가 있을 때만 텔레그램 경보 |
| **10분마다** | 기억 백업 | (조용히) 되돌릴 수 있게 저장 |
| **매일 오전 9시 반** | 스스로 업데이트 | (조용히) 저희가 개선한 것을 받아감 |

**사장님이 하실 일은 없습니다.** 맥미니 전원만 꽂혀 있으면 됩니다.

---

## 2. 직접 시키고 싶을 때

맥미니 터미널에서 아래처럼 부르면 됩니다. (원격으로 부르는 방법은 저희가 따로 열어드립니다.)

```
cd ~/ilson
claude
```

Claude 가 열리면 아래 네 가지를 칠 수 있습니다.

| 치는 것 | 하는 일 |
|---|---|
| `/briefing` | 아침 브리핑을 **지금** 한 번 더 |
| `/weekly` | 주간 보고를 **지금** 만들기 |
| `/tidy` | 위키를 **지금** 정리 |
| `/onboard` | 회사 이야기를 **더 알려주기** (첫날 인터뷰의 이어달리기) |

그냥 **평범한 한국어로 부탁하셔도 됩니다.**

> "지난주 매출 얘기 어디에 적어놨지?"
> "거래처 김 사장님 미팅 내용 기록해줘"
> "이번 달 정리해서 보여줘"

끝내실 땐 `/exit` 를 칩니다.

---

## 3. 일손의 기억 — 볼트

일손이 아는 것은 전부 `~/ilson/vault/` 폴더 안에 **읽을 수 있는 글**로 있습니다. 숨겨둔 게 없습니다.

```
vault/
├── CONTEXT.md      회사 한 장 요약 — 일손이 매번 제일 먼저 읽는 것
├── company/        회사에 대해 배운 것들 (사람·거래처·제품·규칙)
├── journal/        날짜별로, 그날 무슨 일이 있었는지
├── lessons/        사장님께 지적받은 것 — 다시 안 틀리려고
└── reports/
    ├── briefing/   지나간 아침 브리핑
    ├── weekly/     지나간 주간 보고
    └── pending/    ⭐ 사장님 승인을 기다리는 초안
```

**옵시디언(Obsidian)** 앱으로 이 폴더를 열면 위키처럼 보고 고칠 수 있습니다. 사장님이 직접 고쳐 쓰셔도 됩니다 — 일손은 그걸 그대로 배웁니다.

### 일손이 틀린 말을 하면

`vault/lessons/` 에 한 줄 적어두시면 됩니다. 그 다음부터 안 틀립니다.

---

## 4. 일손이 지키는 약속

설치할 때 함께 깔린 규칙이고, 일손이 어길 수 없습니다.

**① 밖으로 나가는 건 승인 없이 안 합니다**

메일·문자·SNS·결제·삭제 — 회사 밖으로 나가는 일은 **초안까지만** 만들고 `vault/reports/pending/` 에 둡니다. 사장님이 보고 "보내"라고 하셔야 나갑니다.

> 텔레그램 알림만 예외입니다. 사장님께 보고하는 통로니까요.

**② 없는 사실은 지어내지 않습니다**

수치·기간·성과는 볼트에 적힌 것만 말합니다. 모르면 **"기록에 없습니다"** 라고 합니다.

**③ 볼트 밖은 건드리지 않습니다**

맥미니의 다른 파일을 만들거나 고치지 않습니다.

**④ 비밀은 적지 않습니다**

비밀번호·토큰 같은 것은 보고서나 노트에 절대 쓰지 않습니다.

---

## 5. 문제가 생기면

터미널에서 이 한 줄이면 대부분 알 수 있습니다.

```
ilson doctor
```

✅ 와 ❌ 로 상태를 보여줍니다. **❌ 가 있으면 그 화면을 사진 찍어 보내주세요.**

| 이런 일이 | 이렇게 |
|---|---|
| 아침 브리핑이 안 온다 | `ilson doctor` → 사진 |
| 맥미니를 껐다 켰다 | **아무것도 안 하셔도 됩니다.** 스스로 다시 시작합니다 |
| 일손이 이상한 소리를 한다 | `vault/lessons/` 에 한 줄 적어주세요 |
| 새 기능을 쓰고 싶다 | 저희에게 말씀만 주세요. 다음 업데이트로 갑니다 |

---

## 6. 그만두고 싶으실 때

`~/ilson` 폴더를 통째로 지우면 끝입니다. **회사 기록은 전부 그 안에 글로 들어 있으니**, 폴더를 복사해 두시면 일손 없이도 그대로 읽으실 수 있습니다.

가둬두지 않습니다.

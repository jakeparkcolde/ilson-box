# DESIGN v2 — 내 AI 사용 기록

2026-11-15 KST · owner t2v5 · 구현 계약. BRIEF 「Go」가 기존 DESIGN.md의 A 우선/토큰 후속 결정을 대체한다. 출시·운영 적용은 별도 승인이다.

## 범위와 측정
개인 학생이 선택한 실습 폴더 하나의 Claude Code 로그만 수집한다. 회사 모드 공유/회사 런타임 수집은 v1 제외. 설치·라이선스·F8·학습 동의는 이 기능 동의가 아니다. Claude Code 우선, Codex는 인터페이스만 준비 중이며 검증되지 않은 누적 카운터를 더하지 않는다. full Mac 웹 관리자 「자동화·컴퓨터 현황」, Intel/Windows는 CLI 수집·export·link/sync와 사이트 그래프를 사용한다. 강사 전용 코드/학생 비교 UI는 학생 배포물에 넣지 않는다.

도구별: 입력/출력/캐시 읽기/캐시 생성 토큰을 각각 표시한다. 모델은 엄격한 알려진 모델 ID allowlist로 정규화하고 미지원은 null이다. 캐시와 입력의 합집합 의미를 임의로 통일하지 않는다. 목록가 추정 비용은 `추정`, USD, 가격표 출처 URL·확인일·가격표 버전을 표시한다. 가격 미지원/토큰 누락은 비용도 확인 불가다. 구독 청구액/생산성/작업시간으로 부르지 않는다. 모델별 가장 많이 사용한 모델은 관측된 비중복 토큰 기준이다.

통합: 사용한 날짜(두 도구의 날짜 합집합), 관측 세션, 본인이 보낸 대화, 현재/최장 연속 사용일, 최근 30일, 피크 날짜/월. 세션은 전체 로그에서 처음 관측된 날짜에 한 번만 센다(실제 프로세스 시작 아님). 자정을 넘으면 다음 날짜에는 대화/토큰만 추가된다. 도구 간 같은 작업/기기 간 복제 세션은 검증 불가다. 미관측/부분 자료는 0일·미사용·출석/성과 순위로 제시하지 않는다. 연속 사용은 관측된 활성 날짜의 연속이며 오늘 미사용이면 어제까지 이어진 기록을 현재 streak로 인정한다. 연도 히트맵은 주가 세로 열, 요일이 가로 행인 참조 배열, 5단계(0+4), 밝게/어둡게, 키보드 및 날짜별 텍스트 대체를 제공한다.

## 수집·장부
기본 OFF. 켜는 시각 이후만 기본 수집. 별도 선택 `수업 시작일 이후 남아 있는 기록 불러오기`와 YYYY-MM-DD를 명시한 경우만 과거를 읽는다. 실습 폴더 이동 시 새 매핑을 확인하고 기존 장부는 보존한다. 삭제/회전된 공급자 로그에서도 이미 집계한 일별 장부가 남는다. Claude projects의 경로 인코딩은 후보 탐색에만 쓰고 레코드 cwd가 선택 폴더와 정확히 일치하는지 확인한다. 하위/부모 폴더와 다른 계정을 자동 탐색하지 않는다. local-private 설정에만 선택 경로를 보관한다.

Box `state/usage-timeline/` 아래 0700 폴더/0600 파일. 기존 snapshot Git 대상이므로 snapshot.sh 및 Box .gitignore 양쪽에서 명시 제외한다. 원문/제목/명령/파일명/프로젝트명은 파생 장부에 넣지 않는다. 커서는 소스 경로 대신 난수 salt 기반 HMAC, byte offset, inode/크기 메타만 보관한다. 세션/메시지 ID도 HMAC만 보관한다. 입력 symlink/hardlink/다른 UID 거절, 제한된 크기/시간·파일 수, 불완전한 마지막 JSONL 줄은 다음에 재시도한다. OS 락으로 CLI/웹/스케줄러 경쟁을 직렬화한다. unknown format은 partial, 추정 숫자 생성 금지. 자동 tool_result·sidechain·meta 사용자 레코드는 본인 turn에서 제외한다. assistant message ID가 같은 스트리밍 결과는 최신 명시 카운터로 대체해 중복 합산하지 않는다.

일별 ledger row는 계약의 daily row와 같고, 로컬 event 테이블에는 HMAC session/message key·UTC timestamp·정규화 카운터만 남긴다. cursor·동의 구간·revision으로 증분/재시도 idempotency를 보장한다. 이벤트/장부·커서 보관은 최근 366일(연도 보기), 강사 서버는 첫 수신+60일과 수업 종료+60일 중 빠른 시각. 재전송이 보관을 연장하지 않는다. 원자료 없는 이전 날짜는 미관측, 손상/지원 불가 행은 partial이다. 공급자 로그 삭제를 감지해 기존 파생 장부를 소거하지 않는다.

## 동의 상태
`off`(신규 수집·업로드 금지), `on_no_data`, `on`, `partial`; 연결은 독립적으로 `unlinked / linked / revoke_pending`다. 일회 코드 연결에는 별도 sharing consent와 전체 payload 미리보기가 필요하다. off는 즉시 업로드도 중단하지만 서버 기존 자료를 지우지는 않는다. unlink는 수집은 유지하며 업로드를 즉시 중지하고 서버 토큰 철회+자료 삭제를 요청한다. 오프라인이면 revoke_pending을 표시하고 자격을 0600으로 보관해 삭제 재시도에만 사용한다. 로컬 삭제는 수집을 끄고 event/장부/커서를 비우며 서버 삭제와 구분한다.

## 웹·실행
기존 스케줄러 watchdog의 별도 자식 프로세스에서 bounded tick, doctor에서도 실패가 다른 작업을 막지 않게 호출한다. 강의판 doctor/usage 명령에서 수집하고 `ilson usage tick`을 OS 스케줄러에서 선택적으로 호출할 수 있다. 기본 자동 켜기/새 daemon 없음. 동기화는 구성 base URL 없으면 비활성, HTTPS만(테스트 loopback HTTP 예외), 짧은 timeout·지수 backoff, 자격/본문/오류 응답 로깅 금지.

기존 Host/Origin/세션 인증 + require_owner를 유지한다. `/usage-history` 독립 로컬 화면과 그 전용 자산/API·세션 교환만 라이선스 네트워크 확인에서 제외해 만료·오프라인에도 읽기/off/export/delete 가능. 일반 관리자 라이선스 경계는 유지. F8 계정 한도 패널은 그대로 두고 타임라인과 별개라고 설명한다.

## privacy — 배포 문구
사용 기록과 강사 공유는 각각 기본 꺼짐입니다. 본인이 고른 실습 폴더에서 관측된 날짜·도구·모델·세션·본인 대화 횟수·토큰 숫자만 집계합니다. 대화 본문, 제목, 파일명, 경로, 프로젝트명, 컴퓨터명, 사용자명은 요약·전송에 포함하지 않습니다. 강사 Jake에게 공유할 JSON 전체를 연결 전에 볼 수 있습니다. 참여는 선택이며 성적·출석·근무 평가와 연결하지 않습니다. 로컬 기록은 최근 366일, 강사 자료는 첫 수신 후 최대 60일(강의 종료+60일이 먼저면 그날) 보관합니다. 끄기는 새 수집·전송을 멈추고, 연결 해제는 서버 자료 삭제도 요청합니다. 오프라인 삭제 요청은 완료 전까지 대기로 표시합니다. 공급자 원본 로그·사용자가 따로 저장/전달한 사본·OS 백업은 이 기능으로 삭제되지 않습니다. 서버 연결 시 IP 같은 통신 정보가 서버에 보일 수 있으며 수신지 운영·백업 정책은 사이트에서 별도 안내합니다. 후기 공개·설문 연결은 별도 동의입니다.

# 직원 · 조직도 · 스킬

일손 운영 화면의 **직원 · 조직도 · 스킬** 메뉴에서 엽니다. 직접 주소는 `/people`이며 기존 기기 관리자 로그인 세션을 사용합니다.

## 직원과 조직도

1. 조직도에서 부서를 만들고 필요하면 상위 부서를 선택합니다.
2. 직원에서 이름·역할·부서를 입력합니다. 부서를 선택하지 않으면 미배치로 표시합니다.
3. 직원의 스킬 할당에서 설치한 스킬을 최대 10개 선택합니다. 모두 해제할 수도 있습니다.
4. 업무 요청에 참고 자료와 원하는 결과를 입력하고 업무 기록에서 결과와 실제 적용된 스킬을 확인합니다. 완료된 결과는 서류함의 회사 문서에도 저장합니다.

직원은 이 기기의 AI 업무 역할입니다. 별도 로그인 사용자나 실제 직원 계정을 만들지 않습니다. 같은 직원 이름은 허용하며 각 직원은 별도 식별자를 갖습니다. 부서·스킬 이름은 중복할 수 없습니다. 종류별 최대 200개입니다.

부서 순환은 거절하며 직원이나 하위 부서가 남은 부서는 삭제할 수 없습니다. 먼저 재배치하세요. 대기·진행 중 업무가 있는 직원은 삭제할 수 없습니다. 완료·실패 업무 기록은 직원 삭제 후에도 남습니다.

## 지원하는 업무 실행

역할과 활성 할당 스킬을 전달해 Claude가 문서·답변·요약을 작성합니다. 로그인된 Claude CLI가 필요합니다. 모델 호출을 실제 업무 큐에서 수행하며 실패를 완료로 표시하지 않습니다. 연습용 설치는 기존 정책에 따라 외부 모델 호출을 거절합니다.

이 화면은 웹 검색·파일 변경·명령 실행·SNS 발행을 하지 않습니다. 스킬 설치로 실행 권한이 추가되지 않습니다. 기존 리서치·모션·SNS·예약 업무는 각자의 실행·승인 정책을 유지하며 이 직원 할당이 자동 적용되지 않습니다.

업무 실행 직전에 직원의 최신 역할과 **할당되어 있고 활성인 스킬**만 읽습니다. 대기 중 스킬 편집·해제·비활성화·제거도 반영합니다. 대기 중 직원이 비활성화되면 그 업무는 실패하며 모델을 호출하지 않습니다. 이미 시작한 업무에는 시작 시 선택된 지침이 남습니다. 비활성화는 실행 취소가 아닙니다. 완료 결과에 실제 적용한 스킬 이름·식별자를 기록합니다.

## 스킬 설치와 관리

- 제공 스킬: 회의 정리, 보고서 점검의 지침을 미리 보고 설치합니다.
- 직접 추가: 이름·설명·순수 Markdown 지침을 입력합니다.
- 파일 가져오기: 브라우저에서 단일 `SKILL.md` 파일을 읽어 편집기에 넣습니다. 내용을 확인하고 저장해야 설치됩니다. 파일명은 서버 경로로 사용하지 않습니다.
- 편집·활성화·비활성화·제거를 지원합니다. 제거하면 모든 직원의 해당 할당도 같은 트랜잭션에서 해제합니다.

지침은 최대 24,000자이며 가져올 파일은 96KB 이하입니다. 선택적인 YAML 머리말은 한 줄 `name:`과 `description:`만 허용하고 제거합니다. 실제 이름·설명은 화면 필드에서 정합니다. 머리말의 hooks·도구 설정·지원 파일·아카이브·원격 URL 설치와 쉘 동적 치환은 지원하지 않습니다. 설치 시 코드·후크를 실행하지 않습니다. 사용자에게 신뢰받는 지침만 넣으세요.

이는 일손 직원 전용 텍스트 스킬 저장소입니다. 사용자 전역 Claude/Codex 스킬을 스캔·수정하지 않으며 기존 `.claude/skills` 팩을 덮어쓰지 않습니다. 자동 로딩을 켜지 않고 선택한 본문만 실행 입력으로 전달합니다. 기존 실행기의 `--safe-mode`, 무도구, 빈 settings source, 빈 MCP, slash-command 비활성 계약을 유지합니다.

포맷 근거: [Claude Code 공식 스킬 문서](https://code.claude.com/docs/en/skills)는 `SKILL.md` 본문·머리말 및 동적 컨텍스트 확장을 설명합니다. 일손은 위에 명시한 텍스트 부분집합만 가져옵니다.

## 저장·업데이트·복구

직원·부서·스킬·할당은 기존 로컬 `.workspace/work.sqlite3`에 저장됩니다. 서버 시작 시 `people_*` 테이블을 없을 때만 추가하며 기존 업무·계정·서류를 초기화하지 않습니다. 반복 시작·코드 업데이트·재설치에서도 장부가 유지됩니다. 배포 파일에는 이 장부를 포함하지 않습니다.

변경은 기존 업무 장부 잠금과 트랜잭션을 공유합니다. 부서·할당의 존재와 삭제 참조를 그 트랜잭션 안에서 확인합니다. 스킬·직원 삭제의 할당 정리도 원자적으로 처리합니다. DB를 외부에서 직접 편집하는 것은 지원하지 않습니다. 기존 장부의 경로·소유권·권한·심볼릭 링크 검사도 그대로 적용합니다.

관리자를 멈추고 `.workspace`와 `vault`를 포함한 기기 데이터를 백업하세요. 코드 원복은 사용자 장부를 지우지 않습니다. 사용자 데이터를 실제로 제거하려면 별도 백업·삭제 판단이 필요합니다. 단순 스킬 제거는 업무 기록과 완료 문서를 삭제하지 않습니다.

## 검증 범위

자동 시험은 가짜 모델 응답으로 실제 subprocess 호출 인자와 입력, 큐 상태, 저장 문서, 세션·출처 경계, XSS 출력 처리, 경로 입력·심볼릭 링크, 참조 무결성·동시 변경·실패 롤백, 기존 장부 이행을 확인합니다. 실제 Claude 계정의 응답 품질·과금·새 기기 운영 설치는 별도 확인 대상입니다.

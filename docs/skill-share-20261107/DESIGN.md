# 스킬 나눔 설계 · 2026-11-07

## 흐름

로컬 `.claude/skills/<이름>`의 텍스트를 제한된 크기·개수로 읽고 파일명과 내용, 볼트 `company/`의 식별 가능한 고유 이름 및 개인정보·비밀 패턴을 검사한다. 발견 위치를 보여 주고 차단한다. 통과 시 전체 내용을 표시하고 실제 TTY에서 확인받아 전송한다. 패턴 검사는 완전한 개인정보 탐지가 아니므로 사용자와 강사가 내용을 직접 확인한다. 실행 파일과 링크는 허용하지 않는다.

현재 구현은 평면 폴더의 UTF-8 Markdown 최대 10개·합계 48,000바이트로 좁혔다. `company/`의 파일·폴더명과 명시적 이름 필드에서 후보를 추출한다. 자유 문장에 숨은 모든 이름을 알아내지는 못한다. 명령과 외부 연결도 차단한다. 받기는 확인 후 서버에서 같은 내용을 다시 확인해 변경·철회된 자료를 설치하지 않는다.

서버는 새 항목을 대기 상태로 보관한다. 강사만 대기 내용을 보고 승인·반려·공개 중지할 수 있다. 목록과 받기는 승인 상태에만 접근하며 제출자도 철회할 수 있다. 기수와 무작위 별칭만 공개하고 발급 기록의 이름은 노출하지 않는다. 기수별 제한은 서버 설정으로 선택한다. 받기 전 전체 내용을 표시하고 실제 TTY 확인 후 별도 이름의 새 스킬 폴더에 출처와 함께 저장하며, 기존 파일을 덮거나 실행하지 않는다.

## 서버와 보안

별도 migration으로 비공개 스키마의 공유 항목·상태와 API 함수를 추가한다. 요청마다 기존 시리얼 서명, 기간, DB 레코드, 기기 등록, 폐기·납부 상태를 검사하며 통신 실패나 오프라인 유예는 공유를 허용하지 않는다. 상태 검증과 자료 접근은 같은 DB 트랜잭션에서 수행한다. 관리자 API는 별도 기존 관리자 비밀과 제한을 사용한다. 크기·형식 및 호출 횟수 제한을 서버에서도 강제하고 직접 테이블 접근을 차단한다. 목록에는 승인된 항목만 제공한다. 코드·스크립트·링크를 사용하지 않는 텍스트 형식으로 제한하며, 업로드를 받은 데이터로 신뢰하지 않는다.

강사용 화면은 학생도 쓰는 기존 Box 관리자에 관리자 비밀을 배포하지 않도록 Studio의 별도 loopback 전용 화면으로 구현했다. 강사가 비밀을 터미널에 숨김 입력하며 비밀은 브라우저나 파일에 보내지 않는다. 실제 내용은 HTML로 해석하지 않고 텍스트로 보여준다. 비밀은 기존 라이선스 관리자 비밀과 같다. 별칭은 공유 건마다 무작위 생성한다.

## 시험과 반영

합성 값으로 민감 패턴·정상 텍스트, 파일 수·크기·경로·링크·중복, TTY 동의, 시리얼과 온라인 상태, 서버 권한·승인·철회·기수 제한을 시험한다. 서버는 격리 DB, 양 클라이언트와 기존 전체 시험 및 `check_public`을 실행한다. 운영 DB 적용·배포·공개판 갱신은 하지 않는다. Mac 공개판 고정 검사가 바뀐 파일을 차단하면 그대로 기록하고 릴리스 시 새 산출물·매니페스트 생성과 재검증이 필요하다. Windows 실기와 보안 독립 검토는 별도로 남긴다.

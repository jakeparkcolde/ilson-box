# 일손 Box 안전 업데이트 적용 기록 — 2026-10-13

## 목표·범위

사용자는 제이크의 Mac mini(<운영 맥>)에서 `ilson update` 한 명령으로 리서치뿐 아니라 일손 관리자 등 배포된 코드를 갱신하길 원한다. 운영 데이터에는 영향을 주지 않아야 한다. Tailscale 연결은 확인했으나 작업 맥 계정의 SSH 인증이 거부됐다. 대상 기기에는 직접 적용하지 않았다. 사용자가 최초 설치 명령을 실행하면 된다. 비밀번호·토큰을 요청하거나 저장하지 않았다.

## 사용자 명령

최초 한 번, 일손Box가 설치된 맥미니에서:

```sh
curl -fsSL https://<배포 호스트>/pack-library/downloads/box/install-updater.sh | bash
```

이후 `ilson update`, 확인 `ilson update --check`, 복구 `ilson update --rollback`.
기존 `install.sh`/setup을 다시 실행하지 않아 설정 재설정을 피한다. bootstrap은 현재 ilson 실행 파일의 실제 위치를 확인하고 임시 다운로드 도구를 체크섬 검사한 뒤 코드만 갱신한다.

## 검증

- 전체 149시험 통과. 기존 git pull 덮어쓰기 시험은 새 배포 묶음 경로의 검증으로 교체하되 운영 정보 보존 및 실제 예약 실행기의 프롬프트 회귀를 유지했다.
- 실제 공개 기준 소스로 만든 임시 Box에서 92파일 묶음 적용(39개 변경), 보호 대상 16파일 바이트 동일, 관리자 화면/리서치 파일 확인, 새 CLI --check 통과.
- 롤백 뒤 서버의 실제 HTTPS bootstrap으로 최초 설치 재시험 성공. 보고서/관리자 토큰 동일 확인.
- HTTPS 최신 manifest와 ZIP 다운로드 후 SHA256 일치 확인.
- 실제 제이크 맥미니 설치/로그인/리서치 실행은 미검증. 자동 LLM 호출·메시지 발송·기존 업무 재시작 없음.
- 전용 미리보기나 상주 프로세스 생성 없음. 기존 앱 서버 보존.

## 다음 배포

1. 공개 기준 일손Box 최신 코드와 리서치의 배포 ZIP을 확정한다. 진행 중 미배포 코드는 섞지 않는다.
2. `python3 tools/build_release.py --output <새 폴더> --version <증가하는 숫자.버전> --pack <배포 팩 ZIP>`.
3. 격리 Box의 적용/충돌/복구/보호 파일 동일성을 검사한다.
4. 새 버전 ZIP·릴리스 JSON을 서버에 먼저 올리고 다운로드 검증 후 latest.json을 원자적으로 교체한다. 기존 버전은 보존한다.
5. 제이크 맥미니의 명령 출력으로 설치 버전과 충돌 여부를 확인한다. 사용자 수정 충돌을 강제로 덮지 않는다.

개발 폴더 수정이 자동 배포되는 구조는 아니다. 배포 feed가 갱신돼야 ilson update가 새 버전을 적용한다.

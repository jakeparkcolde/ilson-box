# 자동화·컴퓨터 현황판

현황판은 기존 업무 공간의 사이드바 메뉴 안에서 열립니다. 테마·모바일 메뉴는 업무 공간과 공유합니다. 다른 메뉴로 이동하면 현황판의 자동 조회와 진행 중 요청을 정리하고, 다시 열면 같은 검색·필터·상세 펼침 상태로 새 관측을 요청합니다. 새로고침하면 필터는 초기화됩니다.

설치 후 일손 메뉴의 **자동화·컴퓨터 현황**을 엽니다. 기존 웹 관리자 세션을 사용합니다. 인증이 만료되면 `ilson open`으로 다시 엽니다. 기본 주소는 `http://127.0.0.1:18794/current/index.html?tab=dashboard`이며 관리자 포트를 바꿨다면 같은 포트를 사용합니다. 예전 `/dashboard` 주소도 이 메뉴로 이동합니다.

## 설치와 갱신

이 기능은 별도 설치 옵션 없이 일손 기본 구성에 포함됩니다. README의 새 설치 명령 또는 기존 `ilson update` 경로로 전달됩니다. 기존 회사 자료, 인증 정보, 사용자 예약 설정은 보존합니다. 추가 Python 패키지나 상주 수집기·LaunchAgent를 설치하지 않습니다. macOS Apple Silicon과 Intel 설치를 지원하며 다른 OS의 CPU·메모리·launchd 관측은 지원하지 않습니다.

현황판은 기존 관리자 서비스 일부입니다. 탭을 닫으면 자동 조회가 끝나고, 관리자 종료는 기존 `ilson admin stop`을 사용합니다. 기능만 따로 제거하는 명령은 없습니다. 기존 관리자를 중지해도 예약 업무는 중지되지 않습니다. 설치/업데이트 중 사용자 업무를 새로 등록하거나 재시작하지 않으며 기존 관리자 갱신 정책을 따릅니다.

## 관측값의 뜻

| 항목 | 근거와 한계 |
|---|---|
| CPU | macOS top의 연속 두 표본 중 두 번째 구간, 전체 CPU 사용률 |
| 메모리 | vm_stat의 앱(anonymous−purgeable)·wired·compressed 페이지, sysctl의 전체 메모리 |
| 디스크 | 일손 설치 볼륨의 statvfs 가용 공간. 외장 전체 목록·큰 폴더 탐색 없음 |
| 일손 업무 | jobs.conf와 등록 plist의 일정, 멈춤 표시, 마지막 성공 도장 |
| 다른 자동화 | 현재 사용자의 launchctl list 중 Apple 및 일반 앱 항목을 제외한 등록. 미등록 항목·다른 사용자·시스템 데몬은 발견하지 않음 |
| 실행 중 | launchd가 보고한 프로세스 PID. 업무 진행·완료 보장 아님 |
| 최근 종료값 | launchd의 마지막 프로세스 종료값. 0도 업무 성공 증거가 아니며 실행 전 기본값일 수 있음 |
| 마지막 성공 | 일손 실행기의 성공 도장. 외부 자동화는 도장 없이 성공으로 판정하지 않음 |

등록 프로세스가 없는 상태와 관측에 실패한 상태를 구분합니다. 실패 시 이전 수치가 있으면 **지난 관측 · 갱신 실패**, 없으면 **수집 실패**를 표시합니다. 표본 시각은 갱신 실패 때 바뀌지 않습니다. 표시할 등록이 없는 정상 응답은 **등록 항목 없음**입니다. 샌드박스 설치는 호스트 사용자 예약을 조회하지 않고 관측 불가로 표시합니다.

수집은 화면 요청이 있을 때만 실행하고 30초 동안 재사용합니다. 여러 탭의 동시 수집은 잠금으로 합칩니다. 숨긴 화면은 조회를 멈추며 복귀하면 다시 확인합니다. 명령별 시간 제한은 4초이며 외부 서비스 호출은 없습니다. 원문 오류·명령 인자·환경변수·로그·사용자 절대경로는 API에 보내지 않습니다. 웹에서 실행·중지·재시작·발송하는 기능은 없습니다.

## 후속 범위

cron, PM2, 봇 내부 예약은 현재 발견하지 않습니다. 이들은 각 예약기의 읽기 전용 어댑터와 사용자 연결 설정이 필요합니다. 자동화 식별자만으로 어떤 업무인지 추정하지 않습니다.

LLM 잔여량은 공식 사용량 연결을 구현한 뒤 표시할 수 있습니다. 이번 기능은 로그인 토큰이나 쿠키를 읽거나 유료 호출을 만들지 않습니다. 다중기기는 기기별 인증·연결·폐기 절차가 필요한 별도 기능입니다. 현재는 이 컴퓨터만 관측하고 원격 수집·전송·공개 접속 설정을 추가하지 않습니다.

## 안전한 개발 검증

`HOME`과 `ILSON_HOME`을 임시 폴더로 지정한 `bash ilson setup --sandbox`는 서비스 등록 없이 자산을 복사합니다. 자동화 API는 샌드박스 표시 때문에 호스트 launchd 목록을 조회하지 않습니다. 시험은 `python3 -m unittest discover -s tests -p test_resource_dashboard.py -v`로 실행합니다. 실제 새 맥 설치·서비스 재시작·외부 공개는 이 시험에 포함하지 않습니다.

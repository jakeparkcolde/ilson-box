# 일손 Box 검색 설치 기준 — 2026-09-30

## 기본 배포

새 Box의 기본 검색 도구는 Tavily CLI(`tvly`)이며, 일손 전용 검색 스킬을 템플릿에 포함한다.
공식 스킬을 그대로 내려받아 전역 설치하는 방식 대신, Box의 시간 제한·기록 보존·예약 실행 규칙을 짧은 스킬로 유지한다.
공식 명령 근거: https://github.com/tavily-ai/skills

- CLI가 없으면 Homebrew로 uv를 준비하고 `uv tool install --python 3.12 tavily-cli`로 설치한다.
- 실행 링크는 `~/.local/bin`에 두며 launchd의 기존 PATH에서 찾는다. 기존 tvly는 재사용한다.
- Box의 `.claude/skills/ilson-search`와 `lib/search.sh`는 설치/재설치 시 함께 배포한다.
- 설치 과정은 실제 검색, 전역 스킬 등록, 로그인, 토큰 복사를 하지 않는다.
- `doctor --probe-search`에서 공개 검색 1회를 실행한다. 응답 확인은 인증 완료 또는 잔여 한도 확인과 다르다.
- 설치 실패는 setup 실패로 반환한다. 검색 실패/시간 초과/잘못된 JSON은 성공 또는 빈 결과로 바꾸지 않는다.
- 인증은 새 기기의 계정으로 직접 진행한다. launchd에서는 셸 프로필의 환경변수가 자동 전달되지 않으므로 일반 터미널 검색과 실제 예약 실행을 각각 확인해야 한다.
- 한 검색은 최대 45초, 결과 5건, basic 깊이다. 스킬은 업무당 검색 최대 3회를 지시하며 이 횟수는 소프트웨어 과금 상한이 아니다.
- 외부 정보는 출처 URL·조회일을 붙여 내부 회사 기록과 구분한다. 비공개 노트·개인정보·인증값은 검색어에 넣지 않는다.
- 아침 브리핑의 기존 내부 기록 요약 동작은 유지한다. 외부 검색의 주제·일정은 별도 업무 설정이다.

## 인세인서치 조사

대상: https://github.com/fivetaku/insane-search (README의 최신 안내 v0.16.3, 조회일 2026-09-30).
공개 페이지를 읽는 Claude Code 플러그인이다. 공개 API/피드, curl_cffi, yt-dlp, 브라우저 경로를 사용하며 네이버·유튜브·X 등을 지원 대상으로 안내한다.
일반 검색 결과를 찾는 Tavily의 보완 후보로 본다. 지원 목록은 제공자의 주장이고 새 맥에서의 성공률은 미검증이다.

원본 설치 방법(현재 Box 기본 설치에는 포함하지 않음):

```text
/plugin marketplace add https://github.com/fivetaku/gptaku_plugins.git
/plugin install insane-search@gptaku-plugins
/reload-plugins
```

현재 원본 SKILL.md의 첫 단계에는 선택적인 GitHub 별표 질문이 있고, 실패 시 여러 경로 및 Playwright MCP를 추가 시도하도록 지시한다.
README는 첫 실행 의존성 자동 설치를 안내하며, v0.16.0 릴리스는 일부 폴백 브라우저를 headful 기본으로 전환했다고 설명한다.
따라서 예약 실행에 포함하기 전에는 설치 시 의존성 준비, 질문 없는 실행, 전체 시간 제한과 종료 조건, 실제 Chrome/MCP 가용성을 확인해야 한다.
기존 xAI 인증이 있으면 X 검색을 추가 사용한다는 안내가 있으므로 고객 계정의 의도하지 않은 비용을 막으려면 해당 경로를 명시적으로 설정해야 한다.
기본 기능은 API 키 없이 동작한다고 안내하지만 모든 URL의 성공이나 모든 경로의 무비용을 보장하지 않는다.

## 검증 범위

임시 폴더와 가짜 Tavily 명령으로 배포·재설치·오류·시간 제한·검색어 인자 처리를 시험한다.
실제 새 맥의 Tavily 설치, 로그인, 한국어 품질, Claude의 스킬 선택/실행 권한, launchd 검색은 별도 실기 확인 대상이다.

# 내 AI 사용 기록 보는 법

2026-11-15 · 수강생 안내 · 로컬 구현 검증본. 배포된 버전과 강의 사이트 운영 반영은 강사의 별도 안내를 따르세요.

## Apple Silicon Mac · 일손 Box 전체판

1. 일반 터미널에서 `ilson open`으로 관리자를 엽니다. 왼쪽 **일 → 내 AI 사용 기록**으로 갑니다. **자동화·컴퓨터 현황** 바로 아래에 있습니다. 기존 F8는 **계정 한도**이며 별도 기능입니다.
2. **실습 범위 확인하고 기록 켜기**에서 본인 홈 안의 실습 폴더 절대 경로와 시간대(한국 `Asia/Seoul`)를 입력합니다. 개인정보 안내를 읽고 체크한 뒤 **선택 범위로 켜기**를 누릅니다. 기본은 꺼짐이며 켠 시각 이후만 관측합니다.
3. 과거 기록을 원하면 별도 **남아 있는 과거 기록도 불러오기**를 체크하고 시작일을 선택하세요. 공급자에게 이미 삭제된 기록은 복구할 수 없습니다. 폴더를 옮겼다면 기록을 끈 뒤 새 폴더를 확인하고 다시 켜세요. 원래 폴더의 장부는 남습니다.
4. **통합**은 사용한 날짜·세션·본인 대화·최근 30일·현재/최장 연속 사용·피크 날짜/월을 표시합니다. **Claude Code**는 모델·입력/출력/캐시 토큰·목록가 추정 비용도 표시합니다. 캐시 보관 시간이 없으면 비용은 범위입니다. 가격표 출처와 확인일은 패널에 표시됩니다. Codex는 준비 중입니다.
5. 연도를 선택하고 날짜에 초점을 맞추면 해당 날짜 숫자를 읽을 수 있습니다. 방향키 위/아래는 하루, 좌/우는 한 주입니다. **날짜별 숫자 표**로도 확인합니다. 채운 칸은 관측값(0 포함), 빈 점선은 미관측입니다. 밝기 단계는 관리자 강조색을 따르며 왼쪽 아래의 **테마 전환**으로 함께 바뀝니다. 일부 기록은 누락/지원하지 않는 형식입니다. 빈 날짜를 미사용·결석으로 해석하지 마세요. 세션은 처음 관측한 날에 한 번 세며 자정을 넘은 대화는 다음 날짜에 들어갑니다.
6. 수집은 기존 Box 점검 예약에서 약 10분마다, 또는 **새로 수집**으로 실행합니다. 로그가 지워져도 먼저 집계한 장부는 최근 366일 남습니다. **JSON 내려받기**는 이 기기에 파일만 저장합니다. 저장 위치가 클라우드 동기화 폴더인지 확인하세요.

> 캡처 자리 A: 공통 사이드바에서 「내 AI 사용 기록」 위치와 자동화·컴퓨터 현황의 F8 한도 패널.
>
> 캡처 자리 B: 켜기 폼의 실습 폴더·시간대·별도 과거 불러오기 체크.
>
> 캡처 자리 C: Claude Code 탭의 연간 히트맵·토큰·추정 비용·날짜별 숫자 표(합성 데이터만 사용).

## 강사에게 공유하고 연결 해제하기

강의 사이트가 운영 준비를 마쳤다는 안내를 받은 뒤 이용합니다. 사이트 주소를 임의로 추측하지 마세요. 본인 계정으로 로그인해 해당 강의의 사용 기록 공유 안내를 읽고 일회 연결 코드를 발급받습니다. 유효 시간은 10분입니다.

관리자에서 **연결 전에 전송 JSON 전체 보기**를 먼저 엽니다. 연결 전 enrollment/consent UUID는 null이며 연결 후 사이트가 발급한 가명 UUID로 채워집니다. **강의 사이트에 별도 동의하고 연결**에서 안내받은 사이트 주소(배포 prefix 포함)와 코드를 입력하고, Jake에게 공유한다는 별도 체크를 한 뒤 연결합니다. 코드·기기 토큰을 화면 캡처나 문의 글에 넣지 마세요. 숫자만 동기화하며 대화·제목·파일명·경로·프로젝트명·컴퓨터명·사용자명은 보내지 않습니다.

**로컬 기록 끄기**는 즉시 이후 수집·전송을 중단합니다. 이미 서버에 보낸 자료는 남습니다. **연결 해제·서버 삭제**는 업로드를 멈추고 기존 공유 자료 삭제까지 요청합니다. 인터넷이 없으면 **서버 삭제 대기**가 표시되며 다음 연결 가능한 tick에 다시 요청합니다. 대기 중이면 완료라고 보지 말고 사이트의 본인 자료 삭제 기능도 이용할 수 있습니다. **로컬 파생 기록 삭제**는 이 기능의 장부만 비우며 공급자 원본 로그·별도 사본·이미 공유한 서버 자료는 별도입니다.

> 캡처 자리 D: 전송 JSON 미리보기와 별도 공유 체크(코드와 토큰 제외).
>
> 캡처 자리 E: 기록 꺼짐, 서버 삭제 대기, 서버 삭제 확인 상태.

라이선스 만료·오프라인에도 같은 관리자 연결을 이용해 `/usage-history` 전용 화면에서 본인 기록 읽기·끄기·내보내기·로컬 삭제를 할 수 있습니다. 터미널의 아래 명령도 사용할 수 있습니다. 일반 관리자 다른 메뉴의 이용 권한은 별도입니다.

## Intel Mac · Windows 강의판

이 강의판에는 로컬 관리자 웹 화면이 없습니다. 일반 터미널/PowerShell에서 CLI로 켜고, 연결 후 강의 사이트의 본인 기록 화면으로 그래프를 봅니다. **켜기 전에 개인정보 안내를 읽고 본인이 직접 실행**합니다. 일회 코드는 명령 인자에 넣지 않고 질문이 나오면 입력하세요.

Intel Mac 예시(폴더는 본인의 실제 실습 폴더로 바꿉니다):

```sh
ilson usage on --workspace "$HOME/Documents/일손강의-1기" --timezone Asia/Seoul --consent
ilson usage status
ilson usage tick
ilson usage export > "$HOME/Desktop/일손-사용-요약.json"
ilson usage link --base-url https://강사가-안내한-사이트/learn --consent
ilson usage sync
ilson usage off
ilson usage unlink
```

Windows PowerShell 예시:

```powershell
ilson usage on --workspace "$HOME\Documents\일손강의-1기" --timezone Asia/Seoul --consent
ilson usage status
ilson usage tick
ilson usage export | Out-File -Encoding utf8 "$HOME\Desktop\일손-사용-요약.json"
ilson usage link --base-url https://강사가-안내한-사이트/learn --consent
ilson usage sync
ilson usage off
ilson usage unlink
```

`https://강사가-안내한-사이트/learn`은 설명용 자리입니다. 실제 승인된 주소로 바꿉니다. 연결 명령은 먼저 전체 JSON을 보여 주고 대화형 터미널에서 코드를 받습니다. `--backfill-from YYYY-MM-DD`는 명시한 날짜 이후 남아 있는 기록을 불러오는 별도 선택입니다. `ilson usage delete-local`은 로컬 파생 장부만 지웁니다. 과거 기록 불러오기도 최근 366일만 지원합니다.

강의판은 새 상시 실행기를 설치하지 않습니다. 수업 후 `ilson usage tick`으로 수집·동기화하세요. 강사가 별도 안내한 경우에만 이 명령을 본인 OS 예약에 등록합니다. 동기화 실패는 지수 간격으로 재시도하며 재실행해도 대기 간격을 지킵니다. `status`와 `export`는 보관된 장부를 오프라인으로 읽고 새 수집은 하지 않습니다.

> 캡처 자리 F: Intel 터미널과 Windows PowerShell의 status 출력(가명 UUID는 가림).
>
> 캡처 자리 G: 강의 사이트의 본인 히트맵(사이트 운영 검증 후 촬영).

## 개인정보와 숫자의 의미

사용 기록과 강사 공유는 각각 기본 꺼짐입니다. 참여는 선택이며 성적·출석·근무 평가와 연결하지 않습니다. 로컬 최근 366일, 강사 자료는 첫 수신 후 최대 60일(강의 종료+60일이 먼저면 그날) 보관합니다. 본문·제목·파일명·경로·프로젝트명·컴퓨터명·사용자명은 전송에서 제외됩니다. 서버 연결 시 IP 같은 통신 정보는 서버에 보일 수 있으며 사이트 운영·백업 정책을 함께 확인하세요. 후기 공개·설문 연결은 별도 동의입니다. 로그 숫자는 생산성·정확한 작업시간·실제 청구액·계정 전체 사용량의 증명이 아닙니다. 회사 직원/공동 계정 공유는 준비 중입니다.

Windows Python에 IANA 시간대 자료가 없더라도 UTC와 Asia/Seoul은 추가 설치 없이 지원합니다. 다른 시간대 자료가 없는 경우에는 안내에 따라 지원 시간대를 선택하세요. 원래 로그에 UTC offset이 없는 시각은 추측해 집계하지 않습니다.

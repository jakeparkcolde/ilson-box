2. 확인된 기수를 선택하고 학생을 고릅니다. 수강 등록과 본인 동의·기기 연결이 확인된 학생만 자료를 표시합니다. 미연결·동의 없음·미제출·전송 실패·오래된 자료는 0건과 구분합니다.
3. 학생별 연간 히트맵, 관측 범위·시간대·마지막 동기화·일부 기록 상태를 먼저 확인합니다. 날짜는 학생의 기기 시간대입니다. 최근 동기화 시각은 사용 시각이 아닙니다.
4. 통합 탭은 사용일·관측 세션·본인 대화·연속 사용·최근 30일·피크 날짜/월을 봅니다. 세션은 처음 관측한 날짜에 한 번 센 값입니다. 여러 날짜에 걸친 세션은 대화/토큰이 다음 날짜에도 생길 수 있습니다. Claude Code 탭은 별도 토큰·모델·목록가 추정 비용을 봅니다. 가격 출처/확인일/버전과 cache TTL 미상 범위를 확인합니다. 서로 다른 도구의 토큰·추정 비용으로 성과를 비교하지 않습니다.
5. 비교표는 Jake에게만 보이는 도구 중립 숫자로 한정합니다. 수집 시작일·전체 기간·누락 상태가 다른 사람의 숫자를 같은 조건인 것처럼 비교하지 않습니다. 성적·출석·업무 평가나 순위·후기 효과 입증으로 쓰지 않습니다.

# Windows와 Intel 맥 수강생이 먼저 읽을 안내

1. PowerShell 또는 터미널에서 `claude`를 실행하고 본인 Claude 계정으로 로그인합니다. 명령을 찾지 못하면 창을 닫고 새로 열어 다시 입력하세요.
2. Obsidian을 열고 `문서/일손강의-1기` 폴더를 기존 보관함(vault)으로 엽니다.
3. Orca에서도 같은 폴더를 강사의 안내에 따라 열고 Claude Code를 실행합니다. 화면이 다르거나 폴더가 열리지 않으면 강사에게 알려 주세요.
4. `작업_연습.md`부터 열고 예제 데이터로 연습합니다. 실제 고객 정보와 비밀값은 입력하지 마세요.
5. 막히면 #1기-질문-설치도움에 어느 단계에서 막혔는지 알려 주세요.

6. 학습 기능을 쓰려면 새 터미널에서 `ilson license activate`를 실행하고 전달받은 시리얼을 직접 붙여넣습니다. 시리얼 없이도 Claude, Orca, Obsidian과 볼트는 사용할 수 있습니다.
7. 학습 수집은 처음에 꺼져 있습니다. 기능과 저장 내용을 읽은 뒤 사용자가 일반 터미널에서 `ilson learn enable`을 직접 실행해 확인할 때만 켜집니다. 제안의 확인·승인·거절도 사용자가 직접 합니다.

`시작과_막힘_복구.md`는 Apple Silicon용 일손 Box와 Herdr 기준의 기존 자료입니다. Windows와 Intel 맥에서는 이 안내를 먼저 따르세요.

### 이번 주 일손 리포트

`ilson report weekly`를 실행하면 강의 볼트의 `reports/weekly/`에 최근 7일 보고서가 저장됩니다. 기록이 부족하면 확인 필요로 표시합니다. 사장님이 정한 업무별 기준 시간을 `reports/weekly-input.json`에 `{"baseline_minutes":{"정리":10}}`처럼 분 단위로 넣고, 일지에는 `- [x] [수행:일손] [유형:정리] 업무`처럼 기록하면 절약 시간을 추정할 수 있습니다. 이전 학습 승인 이력을 포함하려면 `ilson learn export-weekly`를 직접 실행하세요. 보고서와 공개 요약은 로컬 Git 이력에 남을 수 있으니 고객 원문이나 비밀을 적지 마세요.

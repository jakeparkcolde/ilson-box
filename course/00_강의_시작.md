# Windows와 Intel 맥 수강생이 먼저 읽을 안내

설치기가 표시한 현재 창 확인 한 줄을 먼저 실행하고, 실제 새 창을 연 뒤 두 번째 확인 한 줄을 실행하세요. `ilson --version`과 `ilson doctor --install`은 시리얼 없이 사용할 수 있습니다. 오류가 남으면 `ilson doctor --install --share`로 만든 TXT/JSON을 직접 검토해 문의할 때 첨부하세요. 공유 참조번호만으로는 강사가 파일을 볼 수 없고, 자동 전송도 없습니다.

Intel에서 Python 3.10 이상이 없으면 일손 도우미가 설치되지 않습니다. 공식 Python 설치 뒤 강사가 준 Intel 강의판 고정 버전 설치 명령을 다시 실행하세요. 일손/Python이 없어도 강사가 제공하는 독립 진단 한 줄은 동작합니다. `—help`가 아니라 `--help`처럼 ASCII 하이픈 두 개를 사용합니다.

1. PowerShell 또는 터미널에서 `claude`를 실행하고 본인 Claude 계정으로 로그인합니다. 명령을 찾지 못하면 창을 닫고 새로 열어 다시 입력하세요.
2. Obsidian을 열고 `문서/일손강의-1기` 폴더를 기존 보관함(vault)으로 엽니다.
3. Orca에서도 같은 폴더를 강사의 안내에 따라 열고 Claude Code를 실행합니다. 화면이 다르거나 폴더가 열리지 않으면 강사에게 알려 주세요.
4. `작업_연습.md`부터 열고 예제 데이터로 연습합니다. 실제 고객 정보와 비밀값은 입력하지 마세요.
5. 막히면 #1기-질문-설치도움에 어느 단계에서 막혔는지 알려 주세요.

6. 학습 기능을 쓰려면 새 터미널에서 `ilson license activate`를 실행하고 전달받은 시리얼을 직접 붙여넣습니다. 시리얼 없이도 Claude, Orca, Obsidian과 볼트는 사용할 수 있습니다.
7. 학습 수집은 처음에 꺼져 있습니다. 기능과 저장 내용을 읽은 뒤 사용자가 일반 터미널에서 `ilson learn enable`을 직접 실행해 확인할 때만 켜집니다. 제안의 확인·승인·거절도 사용자가 직접 합니다.

`시작과_막힘_복구.md`는 Apple Silicon용 일손 Box와 Herdr 기준의 기존 자료입니다. Windows와 Intel 맥에서는 이 안내를 먼저 따르세요.

### 이번 주 일손 리포트

`ilson report weekly`를 실행하면 강의 볼트의 `reports/weekly/`에 최근 7일 보고서가 저장됩니다. 기록이 부족하면 확인 필요로 표시합니다. 사장님이 정한 업무별 기준 시간을 `reports/weekly-input.json`에 `{"baseline_minutes":{"정리":10}}`처럼 분 단위로 넣고, 일지에는 `- [x] [수행:일손] [유형:정리] 업무`처럼 기록하면 절약 시간을 추정할 수 있습니다. 이전 학습 승인 이력을 포함하려면 `ilson learn export-weekly`를 직접 실행하세요. 보고서와 공개 요약은 로컬 Git 이력에 남을 수 있으니 고객 원문이나 비밀을 적지 마세요.

### 로컬 지식 큐레이터

대화가 끝나면 일반 터미널에서 `ilson curator` (같은 명령: `ilson diary`)를 실행하세요. 최초에는 입력 범위와 출력 위치를 읽고 직접 동의합니다. `ilson curator --on`으로 동의만 저장할 수도 있습니다. 외부 AI와 네트워크를 쓰지 않고, 강의 볼트의 `company/**/*.md`, 날짜별 `journal/*.md`, `reports/briefing/*.md`, `reports/weekly/*.md`만 읽어 새 `journal/curator/YYYY-MM-DD.md`를 만듭니다. 수정은 완료를 뜻하지 않으며 체크 표시와 `확인 필요`만 인용합니다. 기존 노트는 바꾸지 않고 같은 날 기본 정리는 한 번입니다. 추가 정리가 필요하면 `--addendum`으로 새 추가본을 만듭니다.

`ilson curator --status`로 확인하고 `--off`로 이후 수동·자동 읽기를 중단합니다. 강의판은 수동 전용으로 예약을 지원하지 않습니다. 로컬 라이선스 캐시가 오래되면 본문을 읽기 전에 `LICENSE_LOCAL_REQUIRED`로 멈춥니다. 사람이 `ilson license status`로 별도 확인한 뒤 재시도하세요. 이 라이선스 확인 명령은 서버에 접속할 수 있습니다.

### 도우미 업데이트·복구

첫 도입은 강사가 제공한 고정 버전 설치 명령을 다시 실행합니다. 이후 `ilson update --manifest <강사가 제공한 JSON 파일>` 또는 강사가 제공한 `ilson update --source-ref <40자리 커밋> --sha256 <해당 설치기 해시>`를 사용합니다. 이동하는 main 주소는 사용하지 않습니다. 검증된 설치기의 도우미 코드만 백업·교체하고 자체 점검하며, 앱 설치·기존 실행기·Python 선택·PATH·볼트는 보존합니다. 최초 고정 정보가 없으면 `PIN_REQUIRED`로 멈춥니다. 한 번 지정한 고정 정보로 다시 확인하려면 `ilson update`를 실행합니다. 새 버전은 강사의 새 고정 정보가 필요합니다. 실패 시 코드를 복구하며 사용자 수정본은 덮어쓰지 않습니다. `ilson curator --off` 후 `ilson update --rollback`으로 직전 도우미 코드를 복구할 수 있습니다. 구판에는 큐레이터 명령이 없을 수 있습니다.

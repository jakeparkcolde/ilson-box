# 폴더

- `company/` — 회사에 대한 사실. 한 주제 한 파일. `status: current` 만 믿는다.
- `journal/` — 하루 한 파일. 한 일·미완료·메모.
- `lessons/` — 사장님 지적·실패에서 배운 것. 같은 지적 두 번 안 받기.
- `reports/briefing/` `reports/weekly/` — 예약 업무 산출물 사본.
- `reports/pending/` — 사장님 승인이 필요한 초안. 여기 있는 건 아직 나가지 않은 것.

GET READY
처음 설정과 연결
필요한 단계를 마치면 일손이 실제 업무를 시작할 수 있습니다.

        
이 화면에서는 확인된 상태와 설정 방법을 안내합니다. 명령을 복사해 일손을 설치한 이 맥의 터미널에서 실행한 뒤, 화면으로 돌아와 새로고침하세요.

        

          
01
Claude 계정으로 로그인
확인 전
본인 계정으로 로그인합니다. 열리는 화면의 안내에 따라 진행하고, 대화가 끝나면 /exit로 나옵니다.
claude
서버에서 상태를 확인하고 있습니다.

          
02
회사 정보와 업무 공간 준비
확인 전
관리 대화를 열어 일손 폴더의 신뢰 여부를 확인하고 회사 인터뷰를 진행합니다. 기존 회사 정보가 있으면 내용을 먼저 확인하세요.
일반 터미널에서 관리 대화 열기
ilson chat
열린 일손 대화창 안에서 인터뷰 시작
/onboard
서버에서 상태를 확인하고 있습니다.

          
03
텔레그램으로 보고받기 선택
확인 전
개인 봇을 연결하면 업무 보고를 받을 수 있습니다. 토큰은 터미널의 숨김 입력에만 넣고, 안내에 따라 텔레그램에서 시작을 누릅니다. 연결하지 않아도 보고서는 이 맥에 저장됩니다.
ilson telegram connect
서버에서 상태를 확인하고 있습니다.

          
04
준비된 예약 업무 시작
확인 전
회사 정보와 자료를 준비한 뒤 예약 업무를 시작합니다. 이 명령은 준비된 업무들을 등록하므로 실행할 일정과 본인 계정의 사용량을 확인하고 진행하세요.
ilson start
서버에서 상태를 확인하고 있습니다.

        

        
연결 상태를 더 확인할 때

        

          
텔레그램 보고·알림
확인 전
상태를 확인하고 있습니다.
ilson telegram status --verify
현재 텔레그램은 보고·알림을 받는 통로입니다. 대화로 업무를 지시하거나 승인을 처리하지는 않습니다.

          
자료 검색과 전체 점검
확인 전
상태를 확인하고 있습니다.
ilson doctor --probe-search
공개 검색을 1회 실행합니다. 검색 서비스의 사용량이 발생할 수 있습니다.
ilson doctor
설치·계정·기기 상태를 함께 점검할 때 사용합니다.

컴퓨터 사용량

CPU는 약 1초 구간의 전체 사용률, 메모리는 앱·유선·압축 메모리 합계입니다. 디스크는 일손이 설치된 볼륨의 사용자 가용 공간 기준입니다.

자동화 관측

이 화면이 확인하는 범위

launchd의 PID는 프로세스 실행 관측이고 종료값 0은 업무 성공 증거가 아닙니다. 마지막 성공은 일손 실행기가 남긴 도장이 있을 때만 표시합니다. 멈춤 기록과 실제 실행이 다를 수 있습니다.

다른 launchd 등록은 현재 로그인한 사용자의 등록 목록입니다. Apple 시스템 항목·일반 앱 항목은 제외합니다. 미등록 외부 예약, 시스템 데몬, cron·PM2·앱 내부 예약은 포함하지 않으며 일정과 결과를 추정하지 않습니다.

LLM 사용량: 공식 사용량 연결이 없어 미표시입니다. 로그인 정보나 쿠키를 읽지 않습니다. 다중기기: 이 설치 기기만 관측하며 다른 컴퓨터에 연결하거나 전송하지 않습니다.

30초 동안 관측값을 재사용합니다. 숨긴 창에서는 자동 조회를 멈춥니다. 새로 확인도 캐시 기간 안에서는 같은 표본을 표시합니다.

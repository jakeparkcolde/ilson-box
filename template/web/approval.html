승인 대기함

내용과 대상 전체를 확인한 뒤 결정하세요. 맥 Box 전용 기능입니다.

휴대폰 승인은 ilson telegram approval-connect로 개인 대화를 연결하고 ilson telegram approval-start로 수신을 시작하세요. 기기 분실 시 ilson telegram approval-stop으로 중지한 뒤 ilson telegram approval-disconnect로 연결을 해제하고 다시 연결하세요.

승인 요청 내용은 이 맥에 보관됩니다. 텔레그램으로 보내면 해당 대화와 기기에도 남습니다. 자동 개인정보 가림은 제공하지 않습니다. 승인 기록은 보관되며, 이 기능의 데이터는 일반 vault/state 스냅샷에 포함되지 않습니다.

vault/reports/pending에 있는 Markdown 초안 파일 이름을 입력하세요. 승인하면 초안을 approved 폴더에 옮기고 일지에 기록합니다.

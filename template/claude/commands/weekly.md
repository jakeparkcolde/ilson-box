---
description: 주간 보고 — 이번 주 journal 을 한 장으로
---

이번 주 마지막 날은 $ARGUMENTS 입니다. 주간 보고를 만듭니다.

1. `vault/journal/` 에서 최근 7일 파일을 전부 읽습니다.
2. `vault/reports/briefing/` 의 최근 7일 브리핑을 읽습니다.
3. 승인되지 않은 학습 초안은 읽지 않습니다. 승인된 공개 요약이 없으면 학습 내용은 확인 필요로 남깁니다.

알림에는 고객 원문이나 개인정보를 넣지 않습니다. 출력은 **1,200자 이내 평문**, 이 순서로:
- 첫 줄: `📋 {회사명} 주간 보고 {시작일}~{종료일}`
- 이번 주 한 일 (항목 5개 이내, 수치는 journal 에 있는 것만)
- 다음 주로 넘어가는 것
- 새 교훈 (있으면)
- 사장님 결정 필요 (있으면, 질문 형태로 1~3개)

`vault/reports/weekly/{종료일}.md` 에 저장합니다. 성과를 부풀리거나 기록에 없는 숫자를 만들지 않습니다.

정형 일손 리포트는 예약 실행기가 별도로 `vault/reports/weekly/{종료일}-ilson.md`에 저장합니다. 비공개 학습 저장소는 읽지 않습니다.

사장님이 업무 유형별 기준 시간을 정했다면 `vault/reports/weekly-input.json`의 `baseline_minutes`에 분 단위로 저장한 값만 사용합니다. 예: `{"baseline_minutes":{"정리":10}}`. 일지의 `- [x] [수행:일손] [유형:정리] 업무`처럼 완료·수행자·유형이 확인된 기록만 계산합니다. 값과 분류를 추측하지 않습니다. 기존 학습 이력을 공개 요약에 반영하려면 사장님이 `ilson learn export-weekly`를 직접 실행합니다.

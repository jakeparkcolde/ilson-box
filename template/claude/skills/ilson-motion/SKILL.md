# 일손 모션그래픽 제작 팩 (베타)

관리자 팩 보관함의 **팩 꽂기**가 HyperFrames·제작 스킬·브라우저·영상 인코더를 준비한다. 관리자에서 10·15·30초 무음 텍스트 소개 영상을 요청하고 미리보기 승인 후 MP4로 저장할 수 있다. 자유로운 장면·자료·내레이션 제작은 이 대화형 스킬을 사용한다. 설치되지 않은 도구를 이미 설치된 것처럼 보고하지 않는다.

## 시작과 도구 준비

- Box 홈에서 실행한다. 기존 프로젝트가 있으면 먼저 상태와 사용자의 수정 범위를 읽는다.
- 새 작업은 Box 홈의 `projects/motion/` 아래 충돌하지 않는 프로젝트 폴더를 만든다. 원본 자료·기존 출력은 덮어쓰지 않는다. `lib`, `web`, `packs`, `.updates`는 작품 저장소가 아니다.
- `node`, `npx`, `claude`를 확인한다. 없으면 필요한 설치와 오류를 설명한다. 예약 업무에서는 설치·로그인·제작을 자동 시작하지 않는다.
- 새 프로젝트 폴더에서 `npx --yes hyperframes@0.8.150 skills update motion-graphics`로 공식 제작 스킬을 준비한다. 긴 영상·여러 장면·내레이션이 필요하면 `skills update general-video`도 실행한다. 명령 실패 시 중단하고 원인을 보고한다. 마크다운 일부만 복사하여 의존 스크립트·폰트를 생략하지 않는다.
- 설치된 `hyperframes/SKILL.md`를 먼저 찾아 읽고, 해당 문서가 안내하는 핵심·CLI·디자인·애니메이션 스킬을 필요할 때 읽는다. 찾지 못하면 설치 실패로 보고한다. 이후 도구 버전·계정·브라우저 준비는 공식 스킬의 실제 점검 결과를 따른다.

## 제작과 납품

사용자가 이미 말한 주제·길이·비율·참고자료를 재질문하지 않는다. 부족한 필수 정보만 묻고 구성 → 장면 → 모션 → 미리보기 → 검토 → 최종 렌더 순서로 진행한다. 실제 요청과 설치된 HyperFrames 스킬의 렌더 승인 규칙을 따른다.

- 무음 모션그래픽은 motion-graphics, 긴 설명 영상은 general-video를 따른다.
- 내레이션은 사용자가 지정한 **Flow 서비스**를 사용한다. 정확한 서비스나 연결이 불명확하면 내레이션 단계에서 확인한다. Higgsfield나 다른 TTS로 임의 대체하지 않는다. 무음 제작은 계속 가능하다.
- 사용자 기기의 구독·계정만 사용한다. 키·토큰을 작품·로그·소스에 넣지 않는다. 외부 유료 생성이나 공개 발행은 요청 범위와 승인 조건을 따른다.
- 실제 프레임과 재생을 검토하고, 도구의 lint/check 결과와 미리보기 한계를 보고한다. 렌더하지 않은 MP4를 완료로 표시하지 않는다.
- 납품은 실제 존재하는 MP4(요청·승인된 경우), 미리보기, 편집 가능한 프로젝트 경로로 한다. 사용한 도구 버전과 실행 명령을 프로젝트에 기록한다.
- 최종 검토까지 끝난 해당 작업 소유의 미리보기 서버·자동화 브라우저만 종료한다. 검토 대기 또는 공유 서버는 유지한다. 이름으로 프로세스를 일괄 종료하지 않는다.

`ilson update`는 이 진입 스킬과 관리자 코드를 갱신한다. 작품 폴더와 별도로 설치한 HyperFrames 도구의 최신화는 구분해서 보고한다.

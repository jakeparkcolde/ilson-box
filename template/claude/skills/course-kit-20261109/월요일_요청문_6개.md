# 월요일에 바로 쓸 요청문 6개

> 부교재 v2.9 · 확인일 2026-11-05

**실제 기록 기반 새 요청문 · 미실행** — 당시 Jake 발언·AI의 원문 요청이 아닙니다.

실습할 때는 첫 줄의 사례 이름(예: 반짝 물 1편·깃밥쿠커)을 [내 가게/업무 자료]로 바꾸고 내 자료를 아래에 함께 붙여 넣으세요.

## 1. 자료를 사실과 질문으로 나누기

```text
실제 기록의 개인정보 가림 사본을 사용합니다.
반짝 물 1편 PLAN.md 가림 사본에서 확인된 사실·출처·확인 질문을 나눠 주세요. 바로 만들 작은 결과는 카드 구성 검토 메모로 한정하고 새 사실은 넣지 마세요.
```

## 2. 손님에게 보여줄 글 쓰기

```text
실제 기록의 개인정보 가림 사본을 사용합니다.
반짝 물 1편 실제 문안의 첫 문장·핵심 설명·다음 행동을 표시해 주세요. 채널 기준과 대조해 읽는 사람이 누구인지, 사람이 확인해야 할 표현이 무엇인지 적어 주세요.
```

## 3. 짧은 영상으로 설명하기

```text

```

## 4. 다른 언어·독자에게 넓히기

```text

남산 두 언어 영상의 실제 첫 질문과 제작 기록으로 공통 사실과 언어별 표현·목소리·제목을 비교해 주세요. 같은 사실을 유지했는지 확인하고 단순 자막 번역이라고 요약하지 마세요.
```


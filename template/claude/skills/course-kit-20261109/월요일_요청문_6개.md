# 월요일에 바로 쓸 요청문 6개

> 부교재 v2.1 · 확인일 2026-11-05

## 1. 자료를 사실과 질문으로 나누기

```text
내 자료를 확인된 사실·출처·확인할 질문·바로 만들 결과로 나눠 주세요.
업무: [내 업무]
자료: [내 자료]
```

## 2. 손님에게 보여줄 글 쓰기

```text
[내 독자]에게 보여줄 소개글 초안을 써 주세요.
첫 문장·핵심 설명·다음 행동을 넣어 주세요.
확인된 자료: [내 자료]
원하는 길이와 말투: [내 기준]
```

## 3. 짧은 영상으로 설명하기

```text
내 자료를 짧은 영상 3장면으로 나눠 주세요.
보여줄 것·말할 문장·확인할 사실을 표로 적어 주세요.
내 자료와 독자: [내 자료·볼 사람]
```

## 4. 다른 언어·독자에게 넓히기

```text
아래 설명의 바뀌면 안 되는 사실을 먼저 뽑아 주세요.
[다른 언어 또는 독자]용으로 바꾸고 원래 뜻과 대조해 주세요.
원문: [내 설명]
```

## 5. 반복할 일을 기준으로 남기기

```text
내 반복 업무의 시작 조건·작업 순서·사람 확인·완료 증거·실패 대응을 정리해 주세요.
내 업무와 현재 순서: [내 기록]
```

## 6. 내 일을 작은 서비스로 구상하기

```text
내가 자주 받는 질문으로 한 페이지 서비스 구상안을 써 주세요.
쓸 사람·문제 하나·필요 자료·첫 화면·완료 기준 3개를 적어 주세요.
반복 질문과 내 자료: [내 자료]
```

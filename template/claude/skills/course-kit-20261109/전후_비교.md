# 위키 전후 비교

> 부교재 v2.1 · 확인일 2026-11-05

서로 다른 새 대화 두 개에 같은 질문을 씁니다. 가능한 경우 같은 도구·모델을 사용합니다.

공통 질문: [내 업무]에서 다음 작업을 시작할 때 먼저 확인할 세 가지와, 자료가 부족하면 나에게 물을 질문 하나를 써 주세요.

위키를 붙이지 않은 첫 대화의 답: ______

두 번째 대화에 세 문서를 붙이거나 첨부하고 요청합니다:

```text
이 위키를 먼저 읽고 답해 줘.
아래 세 문서를 읽고, 읽은 문서 제목과 각 문서의 핵심 한 줄을 먼저 말해 주세요.
문서의 확인된 사실과 작업 기준을 근거로 답하고, 어느 문서를 참고했는지 표시해 주세요.
문서에 없는 내용은 확인 필요로 남기고 나에게 물어봐 주세요.

내 업무 소개.md: [내가 채운 첫 문서]
자주 받는 질문.md: [내가 채운 둘째 문서]
작업 기준.md: [내가 채운 셋째 문서]

공통 질문: [위키 없이 물었던 질문을 그대로 붙이기]
```

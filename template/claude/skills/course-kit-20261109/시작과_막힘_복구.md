# 강의 시작과 막힘 복구

> 부교재 v2.1 · 확인일 2026-11-05

가상 자료로 연습하세요. 이름·연락처·비공개 금액과 비밀값은 넣지 않습니다. 온라인 AI에 보낸 내용은 해당 서비스에서 처리됩니다.

1. **내 경로 고르기:** Apple Silicon Mac은 강사의 설치 안내를 따릅니다. Intel Mac은 필요한 도구가 이미 있는 경우 기존 설치 상태를 확인하고 진행합니다. Intel 실기 검증은 아직 되지 않았습니다. Windows 최소판은 미배포·미검증이며 별도 안내를 기다립니다. 어느 경우든 문서 실습을 선택할 수 있습니다.
2. **로그인 구분:** AI 대화를 쓰려면 선택한 Claude 또는 Codex의 계정과 로그인이 필요합니다. 일손의 일부 업무는 Claude가 필요합니다. 문서만 작성하는 실습에는 AI 로그인이나 인터넷이 필요하지 않습니다. Herdr 데스크톱 앱과 hc는 강의의 에이전트 작업 도구입니다. 각 도구의 설치와 로그인 상태는 직접 확인합니다.
3. **선택 연결:** 휴대폰에서 에이전트를 보는 ColliePWA는 별도로 운영하는 웹앱이며 Tailscale이 필요합니다. Herdr 데스크톱 연동은 별도 설정이며 설치·연결 여부는 직접 확인합니다. 소개: https://colliepwa.dev. 페어링 QR이나 코드는 화면 공유와 캡처를 금지합니다. 텔레그램·SNS 연결과 `ilson start`는 수업 필수 단계가 아닙니다.
4. **막히거나 오프라인이면 즉시 전환:** 설치와 로그인을 중단하고 이 폴더의 `작업_연습.md`를 텍스트 편집기로 엽니다. 제목·목록·표·체크를 바꾸고 저장한 뒤 닫고 다시 엽니다. 이어 위키 세 장을 채웁니다. AI가 필요하면 요청문을 메모해 두고 연결된 뒤 진행합니다. 실행하지 않은 단계는 미실행으로 적습니다. 인터넷 없이 이 폴더에 접근할 수 없다면 강사가 제공한 사본이나 빈 문서로 같은 항목을 작성합니다.

파일명이 `.md.txt`가 아닌지 확인하세요. AI가 파일을 자동으로 읽었다고 가정하지 말고, 내용을 붙이거나 첨부한 뒤 읽은 문서와 근거를 확인합니다.
